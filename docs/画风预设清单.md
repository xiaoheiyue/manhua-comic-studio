# 内置画风预设清单

`config.STYLE_PRESETS` 现有 **47 种**内置画风，按漫画传统与媒介分成 **8 个家族**。
界面「内容分析 → 内置画风（兜底）」用分组下拉展示；handraw-style 编号风格库不可用时，
这些预设就是出图提示词的画风正文（`config.STYLE_PROMPT_MAP`）。

用法要点：

- **先看题材再选画风**，不要一律落回韩漫；分析阶段的提示词已按这个原则改写。
- 同一部作品的角色图、每一格、每一页共用同一套画风，不要逐格换。
- 画风名只留在界面里；送进模型的正文默认不写风格名/作者名，避免被画成标题。
- 新增画风时，`STYLE_PRESETS` 与 `STYLE_PROMPT_MAP` 必须同时补齐，`selftest` 会校验覆盖率；
  正文里不要出现 `写实` / `照片` / `3D` / `CG` 等词，它们会被 `_sanitize_prompt` 替换。

## 分类依据

分组参考的是漫画史与出版传统，而不是单一平台的流行标签：

- 日系漫画：少年 / 少女 / 青年剧画 / 黑白网点 / 赛璐璐 / 四格 / 恐怖 / 机甲 / 水彩 / 昭和；
- 国风与华语漫画：水墨、工笔重彩、新国风、仙侠、连环画白描、港式武侠、港式犯罪；
- 欧美漫画：超级英雄、黑色电影、独立图像小说、报纸连载、波普、奇幻插画；
- 欧洲漫画：法比清线（ligne claire）、法比经典、文艺图像小说；
- 独立与实验：铅笔、木刻、炭笔、像素、剪纸；
- 美术媒介：油画、绘本水彩、黏土定格、丝网印刷、黑白墨线、极简几何；
- 韩漫与条漫：全彩条漫传统（Webtoon），只作为其中一组。
