# 分镜防撞脸 / 防乱入修复报告

日期：2026-10-27  
范围：`comicgen/prompts.py`、`comicgen/castguard.py`（新增）、`comicgen/pipeline.py`、
`comicgen/director.py`、`comicgen/poseplan.py`、`rules/`、`selftest.py`

---

## 1. 结论先行

这次不是"再写几句负向词"能解决的。实测把问题拆成了 **5 条独立链路**，
其中 3 条是提示词结构问题，2 条是工作流/资产问题：

| # | 根因 | 证据 | 修复 |
| --- | --- | --- | --- |
| 1 | 双人身份卡被预算从中间切断 | 旧提示词里出现"眼睛（画面右侧中景，低头）"这种病句 | 双人卡固定 94 字整卡；超预算只整段丢，不切字 |
| 2 | 正向提示词里写"不要画第二个人/没有路人/禁止融合" | 旧 `pipeline.build_shot_prompt` 直接追加这些句子 | 正向只写"只有一位/两位人物""唯一的人影"；否定全部进 `negative` |
| 3 | 双人只有"两人明显不同"这种空话 | 两人卡片特征高度相似时，模型仍会平均化 | `castguard` 生成具体差异对照（脸型/眼型/发型/外套/记忆点）+ 左右分区 + 中间留空 |
| 4 | 单人场景保留"街头/酒馆/人群/路人/对方/肩背" | 旧提示词里"画面另一侧只露出一个模糊的肩背" | 单人场景替换成"空无一人的…"；肩背/半张脸/关系词清洗 |
| 5 | 姿态骨架 `action_04.png` 里叠着两个头 | 第 8 格"货梯门打开"命中单字"打"，挂上该骨架，生成前后两张脸 | `validate_pose()` 拦截；动作词改上下文匹配；选不到就不挂 |
| 6 | 过肩镜头把前景肩背画成第三个人 | 双人过肩实测：林晚+沈砚+左下角多出一个大肩背 | 单/双人过肩一律降斜侧；用门框/桌沿做前景 |
| 7 | 多人画面被硬压成两人或直接拆光 | `cast_policy.max_characters=2`；`_split_multi_character_shots` 把 2 人以上全拆成单人格 | 上限提到 4 人；只拆 5 人以上；3~4 人逐人分块 + 横列留空 + 980/1060 字预算 |

## 2. 代码改动

### 2.1 新增 `comicgen/castguard.py`

纯规则、零模型调用，负责：

- `count_text()`：`画面里只有一位/两位人物，就是 A / A 和 B`；
- `cast_block()`：一人一段，按左→右排序，A 写完再写 B；
- `compact_card()`：94 字短卡，按字段整段丢弃，绝不切字；
- `contrast_block()`：从 `hard_features` 自动生成具体差异；2 人对照，3~4 人逐人列脸/眼/发；
- `spatial_block()`：2 人左/右，3 人左/中/右，4 人从左到右横列，均留空隙；
- `solo_block()`：单人构图锁（特写/近景/中景/全景分别写死取景范围）；
- `depopulate_text()` / `empty_scene_text()`：单人场景去人群；
- `negative_clause()`：按 0/1/2/3/4 人切换负向清单（第 N+1 个人）；
- `prepare()`：只返回 `Shot` 副本，**不改工程数据**；
- `diagnose()`：给 `director.validate()` 提供 `solo_crowd_words` /
  `solo_ghost_names` / `over_shoulder_risk` / `solo_wide_empty` /
  `pair_collision` / `pair_no_sides`。

### 2.2 `prompts.shot_image_prompt()`

- 接入 `castguard`，新增 `isolation` 段落，顺序为：
  `画风锚 → 画风 → 人数 → 角色 → 隔离 → 说话人 → 镜头 → …`；
- 删除旧的人数模板和 `cast_text()` 里的"服装锁定"重复段；
- 超预算只丢可选段 + 缩短画面内容，**不再切角色卡**；
- `_sanitize_prompt()` 增加按逗号切子句，清掉句尾的"不要长风衣"等否定子句。

### 2.3 `pipeline.build_shot_prompt()`

- 不再改写 `shot.description`（旧版每调用一次就叠加一句"画面里只有…"，
  同一格构建两次会重复；现在是幂等的）；
- 不再追加"不要画第二个人 / single subject only / 禁止融合"；
- 过肩降级、人数锁、差异对照全部交给 `castguard`；
- `_split_multi_character_shots()` 从"2 人以上全拆"改成"5 人以上才拆"，
  2~4 人群像保留；3~4 人预算按 980/1060 字放宽；
- handraw 风格已存在时不再叠加 `comic_style_lock`，省预算且去掉"不要每格换风格"。

### 2.4 `director.normalize()` / `validate()`

- 单人描述自动去召唤词、去画面外角色名；过肩统一改斜侧；
- 双人配额调整后可能把双人改成单人，**再跑一次**单人清洗；
- 单人远景/全景补"人物是画面主体"；
- `_to_over_shoulder()` 不再追加"画面另一侧只露出一个模糊的肩背"，
  改成"单人斜侧 + 画外音"；
- 新增 `over_shoulder_risk` / `solo_ghost_names` 等校验代码。

### 2.5 `poseplan.validate_pose()`

- 已知坏图 `action_04.png` 直接拒绝；
- 画面上方 32% 没有近白色头部关键点的骨架拒绝（`views/` 下大量无头骨架）；
- 动作词改上下文匹配：`打开`、`走廊`、`冲突` 不再误触发 `打/走/冲`；
- 选不到有效骨架时返回空，让提示词接管，不用坏骨架硬控构图。

## 4. 已知限制与下一步

1. **纯提示词双人上限约 70~75%**，3~4 人会更低（越靠后的人越容易被边缘化）。
   要再往上必须上区域控制（Regional Prompter / Attention Couple）或真正可用的
   角色参考工作流。单格默认上限 **4 人**（`MAX_CHARACTERS_PER_SHOT`，可调），
   5 人以上自动拆成群像 + 单人反应格。
2. **`style_ref` 工作流不可用**：实测 3 张参考图会出棋盘格伪影，
   已放弃；`style_color` 只做 ColorTransfer，角色图不进模型。
3. **FD-010 画风偏全身**：单人近景仍可能画成全身，提示词已写
   "腰部以下在画面之外"，但不稳定；必要时在成品层裁切或换更偏半身的画风。
4. **姿态库需要重建**：`views/` 下多数骨架无头部关键点，`actions/` 里
   `action_04` 是双头坏图。当前策略是"宁可不挂"，动态姿态控制能力有限。
5. 本报告只修了分镜出图链路；`studio.py` 的贴纸/图文卡提示词里仍有正向否定，
   属于另一条产品线，未纳入本次改动。
