# 参考资料工作流分析（与当前项目相关的部分）

本轮只保留对本项目 **Z-Image-Turbo + 8GB** 可落地的内容；不直接复制别人的模型链。

## 1. `03.17-自定义人物姿势动作`

文件：`工作流/Flux 角色+姿势一致性.json`

关键参数：

- `ControlNetApplyAdvanced`：strength `0.6`，start `0`，end `0.85`；
- `SetUnionControlNetType`：`openpose`；
- `KSampler`：8 步、cfg 1、denoise `0.5`（第二遍）；
- 先出角色，再用姿势骨架做第二遍；
- 输出后用 `easy imageSplitGrid` 切多视图。

可借鉴：

- **姿态用骨架，不靠文字**；
- 二遍采样 denoise 不要 1.0；
- 角色总图和裁剪图分开保存。

本项目落地：

- Z-Image 的 `QwenImageDiffsynthControlnet` 用 strength `0.85`、8 步、denoise `1.0`（纯文生图 + 骨架），
  比“主视图 init + 0.5 denoise”更稳；后者在 Z-Image 上容易不跟骨架。
- 不引入 Flux ControlNet / Flux Union 权重。

## 2. `06.04-AI固定角色+精准大动态姿势生成技巧`

文件：`工作流/动漫文生图工作流.json`

关键参数：

- 三路 ControlNet：Canny `0.3`、Depth `0.3`、OpenPose `0.9`；
- 角色固定靠提示词 + 参考图 + LoRA，不是单独的身份模型。

可借鉴：

- OpenPose 权重可以到 `0.9`；
- 动作格可以叠加深度/边缘，但 8GB 不建议三路同时开。

本项目落地：

- 只用 **一路 Pose ControlNet 0.95**；
- 分镜需要构图控制时，先用提示词写清机位/景别，不叠三路。

## 3. `05.15-人物一致性 姿势随心变`

文件：`工作流/一张图生成多动作(保持服装一致性).json`

关键参数：

- Flux Redux + 角色参考；
- ControlNet OpenPose `0.74`；
- 两段 KSampler（25/30 步）。

可借鉴：

- “一张图 -> 多动作”适合做姿态库；
- 角色参考和姿态控制分两条链路，不要混成一个 conditioning。

未采纳：

- Redux / StyleModel / CLIPVision 是 Flux 链路，Z-Image 8GB 没有对应权重；
- 25~30 步对 Turbo 无意义，仍用 8 步。

## 4. `2026.03.21人物一致性`

文件：`空白工作流.json`（441 节点）

关键：

- 16 张参考图 + 15 个输出；
- `TextEncodeQwenImageEditPlus` + `Qwen Image Edit Plus`；
- 每路独立 KSampler/VAEEncode，按角度切换；
- 骨架图库包含全身正面/侧面/背面、半身、过肩、特写。

可借鉴：

- **一套角色图要覆盖多角度**；
- 骨架图库按“全身/半身/过肩/特写”分类；
- 每个角度单独出图，不在一张图里硬塞所有角度。

未采纳：

- Qwen Image Edit Plus 需要另一套编辑模型/权重，8GB 和当前 Z-Image 链不兼容；
- 441 节点工作流不适合直接嵌入本项目。

本项目落地：

- 姿态总图负责“多角度总览”；
- 主视图只保留正面全身；
- 分镜需要特殊角度时，用本格自定义骨架 + Pose ControlNet。

## 5. `2026.04.02-一键多角度角色`

文件：`工作流/一键多角度角色.json`

关键：

- 9 个相机提示词：低角度、左/右 45°、左/右 90°、俯视、特写、广角；
- 仍然用 Qwen Image Edit 的图生图链。

可借鉴：

- 角度提示词可以单独作为“镜头角度”；
- 不要把所有角度塞进一张图。

本项目落地：

- 分镜层已有 `camera` / `composition` / `lens` 字段，角度走文字；
- 角色层面只保留主视图 + 姿态总图，避免多套参考图互相污染。

## 6. `2026.07.25-Krea2+Z-Image 4K`

文件：`Krea2+Z-Image工作流.json`

关键：

- Z-Image 负责主体，Krea2 负责风格/细节；
- 最后 SeedVR2 + `ImageUpscaleWithModel` 做 4K；
- 有 8 步 Z-Image 采样器 + 低强度 LoRA。

可借鉴：

- 最终成图可以做一次 **模型放大**，而不是只靠 PIL 拉伸；
- 放大放在最后，不参与角色一致性生成。

当前未启用：

- 本机没装 SeedVR2 节点和对应 VAE；
- 4x 放大模型不在共享 models 目录；
- 8GB 先保证 1536 姿态图 / 1024×1536 主视图，不追加放大链。

## 7. 提示词参考

`参考资料/2026.04.23-夯到爆的5款AI提示词/`：

- `角色设计大师.txt`：强调脸型/发型/服装/记忆点的可复现描述；
- `分镜大师.txt`：镜头、景别、构图、动作、情绪；
- `25宫格Ver1.0.txt`：多视图网格结构。

落地：

- 角色身份锁采用“脸型/发型/眼睛/服装/记忆点”五段式；
- 分镜仍用现有导演层字段，不把 25 宫格塞进单格；
- 姿态总图用 3 个全身 + 动作/头像的区域结构。

## 8. 结论

| 参考 | 采纳 | 原因 |
|---|---|---|
| OpenPose 骨架 + ControlNet | ✅ | Z-Image 有对应 ControlNet，8GB 可跑 |
| 先总图再裁参考 | ✅ | 解决跨图漂移 |
| 多角度单独生成 | ✅ | 姿态总图 / 本格姿态分开 |
| Qwen Image Edit Plus | ❌ | 需要另一套编辑模型，当前不可用 |
| Flux Redux / ICEdit | ❌ | 与 Z-Image 链路不兼容 |
| Krea2 / SeedVR2 4K | ⏸ | 节点/权重未安装，先不接 |
| LoRA | ❌ | 8GB/16GB 训练不成立，已归档 |
