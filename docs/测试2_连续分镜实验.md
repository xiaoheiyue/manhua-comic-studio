# 连续分镜图链实验（测试2）

目标：按 `分镜内容优化.md` 里的思路，用**上一格分镜图**作为参考，生成下一格，保持角色、光影、画风连续。

## 方法

- 取 `测试2` 第 1 格 `分镜_001_raw.png` 作为 init；
- 用第 2 格的提示词和负向；
- 图生图工作流 `image_z_image_turbo_int8_story_chain`；
- 分别测试 denoise 0.45 / 0.68 / 0.78。

## 结果

### denoise 0.45

- 几乎保留第 1 格构图；
- 只把杯子/手改了一点；
- 没有真正变成第 2 格镜头。

### denoise 0.68

- 背景、人物姿态仍然沿用第 1 格；
- 手机和杯子被“贴”进画面，出现悬浮手机；
- 人物外套变长，开始偏离设定。

### denoise 0.78

- 能变成新的桌面/手机镜头；
- 但角色外套变成长风衣、下装变短，身份和服装都漂移；
- 仍无法同时做到“换镜头 + 锁角色”。

## 结论

**上一格图作 init 的 img2img 链，不能单独解决分镜一致性。**

它适合：

- 同一场景、相邻镜头的氛围/光影连续；
- denoise 0.5–0.6，且镜头变化很小时。

不适合：

- 从“窗边背影”跳到“桌面手机特写”这种大镜头变化；
- 跨场景连续；
- 要求角色服装/脸完全不变的场景。

根因：

- img2img 的 init 同时携带了构图、服装、光影；
- denoise 低 → 构图不变；
- denoise 高 → 身份/服装一起变；
- 没有一个只携带“角色身份”的参考通道。

## 建议

1. 同一场景链：denoise 0.55–0.65，只用于相邻镜头；
2. 跨场景/大镜头变化：不要用上一格 init，改用角色主视图作为身份参考；
3. 真正需要“基础图锁风格 + 换镜头”的，应该用：
   - Nano Banana / Qwen Image Edit 的多图参考；
   - 或 IP-Adapter / ReferenceLatent 的“角色参考 + 新构图”；
4. 下一轮不要继续调 img2img denoise，应该先解决“角色参考进入图像条件”。

## 补充：角色参考工作流实验

试了 `image_z_image_turbo_int8_style_ref`：

- 参考图 1 = 画风图；
- 参考图 2 = 陆鸣主视图；
- prompt = 第 3 格。

结果：

- 画面出现大面积马赛克/彩色噪点；
- 人物轮廓和服装结构被破坏；
- 不能作为生产链路。

结论：

> `style_ref` 这张工作流在 Z-Image 当前权重/节点组合下不稳定。  
> 真正要“角色主视图 + 新镜头”，需要换一条支持多参考的模型链（Nano Banana/Qwen Edit/IP-Adapter），不是继续调这个工作流的参数。
