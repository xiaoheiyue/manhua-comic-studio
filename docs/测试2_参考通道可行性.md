# 角色参考通道可行性（测试2）

目标：主视图 + 新镜头，同一角色、同一套衣服。  
分别检查 Nano Banana / Qwen Image Edit / IP-Adapter。

## 1. Nano Banana

ComfyUI 里有节点：

```text
GeminiNanoBanana2
GeminiNanoBanana2V2
```

但：

- 是 API 节点，不是本地模型；
- 需要 Comfy/Google 的 auth/api key；
- 当前进程没有配置 key；
- 没有 key 不能提交。

结论：**无法在本地 8GB 环境直接跑，需要 API 额度。**

## 2. Qwen Image Edit

本地有：

```text
diffusion_models/qwen_image_2.1_turbo_int8_convrot.safetensors
vae/qwen_image_2.1_vae_bf16.safetensors
```

但模板要求：

```text
text_encoders/qwen3vl_8b_int8_convrot.safetensors
```

当前只有 `qwen_3_4b_fp8_mixed`，不是 Qwen3-VL-8B。  
缺少正确的视觉文本编码器，Qwen Image Edit 本地跑不起来。

另外：

- 8B text encoder int8 约 8.7GB；
- 加上 6.76GB 扩散模型，8GB 显存 + 16GB 内存基本不可行。

结论：**模型不全，且硬件不够。**

## 3. IP-Adapter

检查 ComfyUI 节点与模型目录：

```text
没有 IPAdapter 节点
没有 ip-adapter 模型
```

结论：**当前未安装，无法测试。**

## 4. 唯一能跑的本地方案：上一格 img2img

见：

- [连续分镜实验](docs/测试2_连续分镜实验.md)

结果：

| denoise | 结果 |
|---|---|
| 0.45 | 构图不变，只改杯子/手 |
| 0.68 | 背景/姿态不变，手机像贴上去 |
| 0.78 | 能换镜头，但外套/下装漂移 |

结论：

> 上一格 img2img 只能做同场景小镜头连续；  
> 不能同时完成“换镜头 + 锁角色”。

## 5. 结论

三条参考通道全部被环境卡住：

- Nano Banana：缺 API key；
- Qwen Edit：缺 qwen3vl_8b，且 8GB 跑不动；
- IP-Adapter：未安装。

下一步只有三条现实路线：

1. 接 Nano Banana API（最省本地硬件）；
2. 升级内存/显存后跑 Qwen Edit 本地；
3. 安装 IP-Adapter（如果 Z-Image 有可用权重）。

在其中一个落地前，不应该继续承诺“角色参考锁定”。
