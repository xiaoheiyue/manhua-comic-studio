# 创作工坊（非漫画）

> **2026-11-04 全功能回归**：7 种模式全部跑过，并修了表情包双角色/九格重复、
> IP 伪汉字、电商图商品被画风替换、插画跑题、信息图空白/脏底/冒号节点、
> 参考图输出画幅等问题。完整测试矩阵、前后对比与检索依据见
> [创作工坊 2026-11-04 测试与优化](创作工坊_20261104_测试与优化.md)。

独立菜单：使用 `handraw-style/` 的 365 种画风、167 种版式、36 种主题色，
生成漫画以外的内容。它不读取小说工程，也不参与 8 步漫画流程。

## 支持的用途

| 用途 | 版式来源 | 默认画幅 |
|---|---|---|

## 关键设计

### 1. 不写“漫画”

风格库里原本有“漫画分级特征”，Z-Image 会把它理解成画分镜格。
创作工坊会把这段替换成“画面风格特征”，并去掉“漫画”字样；
版式也排除 comic-storyboard。

### 2. 先语义编译，再出图

Qwen-Image-2.1 的文本编码器本身是语言模型，它更擅长“观察式描述”，
而不是 SD 风格标签或一段塞满抽象要求的长句。社媒图文 / 信息图默认先走一层
LLM 语义编译：

```text
用户中文主题
→ 首句定框架：媒介 / 主体 / 底色 / 风格 / 配色
→ 观察式视觉描述：人物、动作、空间、材质、光影
→ 信息图：只生成低对比纸感底图；节点、关系、标签由程序排版
→ 社媒图文：插画 + 底部标题/要点面板
```

- 改写结果会显示在「预览改写」里，可关掉开关做 A/B 对照；
- LLM 失败 / 超时会自动回退到本地模板，不阻塞出图；
- 信息图节点和关系来自 LLM 的 JSON 计划，不再赌模型能不能画出“信息结构”；
- 需要精确呈现的中文（标题、节点标签、要点）全部由程序叠加，不进入 T2I 提示词；
- 抽象词（悲凉、命运、层次）在改写阶段被翻译成可见的人物/动作/空间/光影。

### 3. 中文标题程序叠加

模型写中文标题容易重复/错字。海报/社媒/信息图默认：

```text
模型只画画面，不画文字
→ PIL 叠加中文标题与副标题
→ 裁掉模型在顶部/底部写的乱字
```

信息图使用程序时间线：标题 + 节点卡片 + 节点间关系 + 出处标签；
社媒图文使用底部半透明文字面板，保留完整插画。
标题和节点标签 100% 正确，画面也不会被乱码污染。

### 4. 风格参考

仍然使用 handraw 风格图作为 `style_color` 参考；
风格由 `stylelib.style_prompt_block()` 生成，颜色由 C-* 主题色控制。

- 海报：秋分 / FE-053 / 柿子橙 + 普鲁士蓝，标题干净；

## 边界

- 中文长文案仍建议后期排版，不建议全部交给模型；
- 表情包支持 3×3（9 格）与 4×4（16 格）；有参考图时逐格生成后拼网格；
- 表情包的少数格子仍可能脸型漂移，这是 Z-Image 单图参考的限制；
- 信息图的文字/节点/关系由程序排版，底图只负责纸张与墨色质感；
- LLM 改写不可用时自动回退本地模板，信息图语义会弱一些，但结构仍成立。


## 参考图生成（已支持）

创作工坊支持上传一张参考图：

```text

```

界面：`参考图（可选）→ 上传参考图`。

生成逻辑：

```text
有参考图：
  Z-Image img2img
  保留主体结构/配色/角色特征，按新主题重画
  不是直接复制原图

无参考图：
  style_color 文生图 + handraw 风格参考
```

适合：

- 同一个角色做一套表情包；
- 同一只宠物换动作/表情；
- 同一产品做不同海报；
- 同一 IP 做头像/贴纸/社媒图。

实测：

- 上传一张 3×3 橘猫贴纸；
- 主题改为“同一只橘猫的九种新表情”；

- [参考图生成结果](outputs/创作工坊/20261025_104028/emoji_FA-018_1004050762.png)

边界：

- 参考图越干净、主体越清楚，保留越稳；
- 参考图里的文字/水印不会被主动保留，但可能影响画面；
- 不是角色 LoRA，极复杂的服装/脸仍可能漂。


## 表情包参考图（逐格生成）

之前直接把参考图铺成 4×4 再 img2img，会得到“同一个站姿复制 16 次”。

现在改成：

```text
参考图
→ 第一步：转成 Q 版 chibi 底图（denoise 0.70）
→ 裁到头肩
→ 第二步：逐个表情生成（denoise 0.58）
→ 拼成 3×3 / 4×4 贴纸表
```

所以：

- 第一步只做一次 chibi 底图；
- 3×3 再生成 9 次；
- 4×4 再生成 16 次；
- 每格表情不同，不再是同一张站姿；
- 参考图只保留脸/发型/服装，不复制构图。

实测（4×4）：

- 个别格子的发丝/服装细节会漂；
- 参考图如果是 3D/写实，chibi 化后服装会简化；
- 要严格 1:1 还原服装，仍需要角色 LoRA / 多图参考。

## 表情包文字：模型直接写（Qwen-Image-2.1）

不再是固定问候语，也不再把同一套“谢谢/好的/晚安”硬贴到所有角色上。

### 三种文字模式

```text
模型直接写在图里（默认）
程序叠加固定文字（文字更准）
不要文字
```

默认：**模型直接写在图里**。

- 文字框留空：模型按表情自动写 2–6 字反应词/拟声词；
- 文字框填写：按格子顺序让模型写这些词；
- 同时生成手绘特效：爱心、火焰、汗滴、速度线、感叹号等。

### 自动反应词

留空时使用与表情一一对应的短反应词：

| 表情 | 文字 |
|---|---|
| 开心大笑 | 哈哈 |
| 无语 | …… |
| 震惊 | ？！ |
| 生气 | 哼！ |
| 委屈 | 呜呜 |
| 思考 | 嗯… |
| 比心 | 爱你 |
| 困倦 | 困… |
| 点赞 | 赞！ |

这些不是问候语，是“表情反应”；也可以完全自定义。

### 实测

![Qwen 模型写字 9 格](outputs/测试_qwen_模型写字9.png)

- 同一角色、同一套衣服；
- 文字由模型直接写在图里；
- 带爱心、火焰、汗滴、速度线；
- 文字可读，不再是固定问候语。

### 注意

- Qwen 写中文偶尔会错字，尤其是 4×4、字很多时；
- 要求文字准确时，选“程序叠加固定文字”；
- 模型写字模式更适合表情包、贴纸、社交图。


## 参考图换了但输出没变：已修

原因有三层：

1. 上传文件名相同，ComfyUI 的 `LoadImage` 命中了旧缓存；
2. 换图后 seed 不变，输出容易复用旧构图；
3. 提示词没有描述参考图特征，Qwen 会自己发明发色/服装。

修复：

- 每次上传使用**内容 hash + 随机名**，不再复用同名文件；
- seed 加入参考图 hash，换图必换 seed；
- 提示词加入**参考图主色**和主题描述；
- 参考图预览立即更新。

验证：

- 上传紫色长发参考图；
- 输出为紫色长发角色，不再是上一张棕发角色。

![紫色参考图 9 格](outputs/创作工坊/20261026_211008/emoji_FE-034_1583922975.png)

## 身份优先：不再重画角色

之前用 Qwen Edit `denoise=1.0`，等于把参考图完全重画，所以只剩颜色像。

现在表情包默认：

```text
身份优先 = 开启
参考图直接当母本
只做低去噪 img2img（denoise 0.75）
```

效果：

- 脸型、发型、发色、星空裙、发饰保持不变；
- 只改变表情和手写文字；
- 9 格是同一个角色，不是 9 个紫发角色。

![身份优先 9 格](outputs/创作工坊/20261026_213215/emoji_FE-034_2037607033.png)

使用条件：

- 参考图本身是 Q 版 / 立绘时，保持「身份优先」开启；
- 参考图是真人照片、想转 Q 版时，关闭「身份优先」，走完整重绘；
- 文字方式选「模型直接写在图里」，文字会跟表情一起生成；
- 要求文字 100% 准确时，选「程序叠加固定文字」。


## 参考图三种处理方式

不是所有参考图都用同一种出图。

| 参考图类型 | 模式 | 行为 |
|---|---|---|
| Q版 / 立绘 | 身份优先 | 直接当母本，0.75 去噪只改表情，脸/衣服最稳 |
| 真人 / 3D | 先转 Q 版 | 先用 Qwen Edit 转 chibi 母本，再用母本做表情 |
| 只要画风 | 只参考画风 | 不锁人物，重新生成 |

页面：

```text
参考图类型：
  Q版 / 立绘：身份优先
  真人 / 3D：先转 Q 版，再锁母本
  只参考画风：不锁人物
```

注意：

- Q版参考图选“身份优先”，脸最像；
- 真人照片直接低去噪只会得到真人感，不会变 Q 版，要选“先转 Q 版”；
- 只参考画风模式不保证人物一致。


## 固定种子与缓存：同一参考图不再随机

表情/文字每次不一样，是因为之前种子是随机的。

现在：

```text
随机种子：888001（默认固定）
每次随机：关闭（默认）
```

行为：

- 同一张参考图 + 同一风格 + 同一组文字；
- 生成结果完全一致；
- 第二次生成直接命中缓存，0 秒返回；
- 想换一批：改种子，或勾选“每次随机”。

缓存键包含：

```text
参考图内容 hash
模式 / 风格 / 主色
格子数量 / 文字模式 / 文字内容
主题 / 标题 / seed / 参考图类型
```

换参考图、换风格、换文字、换 seed 都会生成新图，不会拿旧图糊弄。


## 全部 7 种模式统一优化

海报、社媒图文、信息图、表情包、插画、IP/头像、电商图现在共用同一套策略：

- Qwen-Image-2.1：有参考图走 Edit，无参考图走 T2I；
- 社媒图文 / 信息图先做 LLM 语义编译，再进入文本编码器；
- 固定种子 888001 + 结果缓存；
- 参考图三种处理：保留原图 / 重绘 Q 版 / 只参考画风；
- 365 个风格缩略图、119 个版式预览、主色色块；
- 标题、价格、说明文字由程序叠加，避免模型写错；
- 表情包额外支持模型直接写反应词和特效。

同参数第二次生成会命中缓存，0 秒返回同一张。


## 换风格测试

同一张紫发参考图、同一 seed、不同风格：

- FA-018：更明显的线稿、腮红、手绘感；
- FE-034：更柔和的水彩、低对比、柔光。

结果：

- 脸、发型、星空裙主体保持不变；
- 线条、色彩、柔光、部分衣饰随风格变化；
- 说明“身份优先”不是完全拒绝风格，风格变化是温和的。

如果要做“画风大改”，要选“只参考画风”，不要用身份优先。
