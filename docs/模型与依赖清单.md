# 模型与依赖清单

本项目**不附带模型权重**。运行前需要：Python 依赖 + 本地 ComfyUI + 下图模型文件。

> 逐文件的完整清单（9 个权重、SHA256、许可证、来源）在 [models/README.md](../models/README.md)，
> 机器可读版本在 [models/manifest.json](../models/manifest.json)；本文只讲最小可跑与放置方式。

## 一、硬件建议

| 项目 | 最低 | 推荐 |
|---|---|---|
| GPU | 8GB 显存（int8 量化，1088×1216 约 20s/张） | 12GB+ |
| 内存 | 16GB | 32GB |
| 磁盘 | 30GB（模型 + 产物） | 100GB |
| 系统 | Windows 10/11、Linux、macOS（Apple Silicon 可跑，速度慢） | Windows 11 + NVIDIA |

## 二、模型文件放哪

统一放进 ComfyUI 的 `models/` 下，目录结构：

```text
ComfyUI/
└── models/
    ├── diffusion_models/
    │   ├── z_image_turbo_int8_convrot.safetensors        # Z-Image-Turbo 主力
    │   └── qwen_image_2.1_turbo_int8_convrot.safetensors # Qwen-Image-2.1（可选）
    ├── text_encoders/
    │   ├── qwen_3_4b_fp8_mixed.safetensors               # Z-Image 的文本编码器
    │   └── qwen3vl_8b_w4a8.safetensors                   # Qwen-Image 的文本+视觉编码器
    └── vae/
        ├── ae.safetensors
        └── qwen_image_2.1_vae_bf16.safetensors
```

> 文件名必须和 `comfy_workflows/*.json` 里写的完全一致，否则 ComfyUI 会报
> `Value not in list`。界面「设置 → 图像工作流 → 检查工作流」会逐个核对。

## 三、模型来源

| 模型 | 官方来源 | 许可 |
|---|---|---|
| Z-Image-Turbo | Hugging Face `Tongyi-MAI/Z-Image-Turbo`；魔搭同名仓库 | Apache-2.0 |
| Qwen-Image-2.1 | Hugging Face `Qwen/Qwen-Image`；魔搭同名仓库 | Apache-2.0 |

下载方式（任选）：

```bash
# Hugging Face CLI
pip install -U huggingface_hub
hf download Tongyi-MAI/Z-Image-Turbo --local-dir ./z-image-turbo

# 或魔搭（国内更快）
pip install modelscope
modelscope download --model Tongyi-MAI/Z-Image-Turbo --local_dir ./z-image-turbo
```

> **量化版权限提醒**：社区 int8 / 4bit 包的许可标注不一定继承原模型的 Apache-2.0，
> 有把量化版误标成 `tongyi-qianwen-license` 的案例。商用请使用官方权重，或确认
> 量化仓库明确继承 Apache-2.0。

## 四、ComfyUI

1. 安装 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)（GPL-3.0，独立程序）。
2. 启动：`python main.py --listen 127.0.0.1 --port 8188`。
3. 本项目默认连接 `http://127.0.0.1:8188`，可在 `.env` 或 `config.py` 改 `COMFY_API_HOST`。
4. 自定义节点：本项目工作流只用到 ComfyUI 自带节点（`UNETLoader` / `CLIPLoader` /
   `VAELoader` / `KSampler` / `TextEncodeQwenImage21` 等）。若你的 ComfyUI 版本较旧，
   缺少 `TextEncodeQwenImage21`，请升级到支持 Qwen-Image-2.1 的版本。

## 五、不装模型也能跑的东西

- `python selftest.py`：离线自检，不调用 DeepSeek、不需要 GPU，验证分段/分镜/版式/气泡/导出全链路。
- 界面可以正常打开、浏览工程、编辑工作流与提示词；只有「出图」与「AI 分析」需要服务在线。

## 六、文本模型

默认 DeepSeek 官方 API（`deepseek-flash`）。任何 OpenAI 兼容端点都可以替换：

```dotenv
TEXT_API_HOST=https://api.deepseek.com
TEXT_MODEL=deepseek-flash
```

也支持本地部署的 Unsloth / vLLM / Ollama（OpenAI 兼容层），把 `TEXT_API_HOST` 指过去即可。
