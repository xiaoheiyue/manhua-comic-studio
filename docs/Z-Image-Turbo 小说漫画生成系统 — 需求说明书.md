# Z-Image-Turbo 小说漫画生成系统 — 需求说明书

> 版本：2026-10（与当前代码一致）
> 模型后端：本地 ComfyUI + **Z-Image-Turbo int8**（不是 Qwen-Image）
> 风格资产：`handraw-style/`（只读嵌入）

## 一、项目概述

### 1.1 项目名称

**Z-Image-Turbo 小说漫画生成系统**，简称“漫画生成器”。

### 1.2 项目目标

构建一个带可视化界面的本地应用：用户上传小说文本或直接粘贴文字，系统自动完成
内容分析、角色人设、主视图与姿态总图、分镜拆解、分页选版式，最后调用本机 ComfyUI 的
Z-Image-Turbo 逐格出图、拼成漫画页/条漫，并打包导出。

系统不再只产出“一格一张的彩色韩漫”，而是同时支持：

- **handraw-style 风格库**：365 种画风、36 种主题色、40 种阶调（16 原始 + 24 扩展）、74 种漫画分镜版式；
- **一页多格**：2~6 格拼成一页，版式按分镜内容自主选择；
- **原条漫 / 分镜页 / 混排** 三种形态；
- **风格触发词**：把风格家族媒介、漫画特征词、阶调与故事内容组合成提示词；
- **复杂风格工作流**：色彩迁移、参考图（实验）、图生图兜底；
- **负面条件**：工作流已接 negative 文本节点，按镜头/角色/风格组合负向词。

### 1.3 核心价值

- **零代码**：无需绘画基础，按五个阶段操作即可出成品。
- **风格可选**：不再是单一韩漫模板，可从 365 种 handraw 画风里自动推荐或手动选择。
- **内容驱动版式**：分镜分析产出叙事功能（beat/pacing/emphasis/caption），再据此选 SB-* 版式。
- **可控可回溯**：每一格的提示词、气泡计划、自检结果、返修记录全部落盘。
- **角色尽量一致**：主视图 + 身份锁（脸/发/眼/服装/记忆点）+ 固定种子 + 负向词；不训练 LoRA。
- **8GB 显存可跑**：Z-Image-Turbo int8、8 步、单张 20~40 秒；OOM 自动降级。
- **成品可读**：对话气泡、旁白条、分格边框、页号、封面/尾页、PDF/条漫长图。

### 1.4 目标用户

- 小说作者、漫画创作者、编剧/分镜师；
- 自媒体、短剧/漫剧前期视觉开发；
- 想低成本把小说可视化的个人用户。

## 三、用户使用流程

### 第一阶段：输入文本

- 上传 `.txt`/`.docx` 或直接粘贴；
- 显示字数、行数；可加载示例；
- 保存为工程，后续可继续编辑。

### 第二阶段：内容分析

- 识别故事梗概、情节线、关键点、角色、场景；
- 角色含性别/年龄/身份/性格/在故事中的作用/是否群众；
- 场景含环境特征、氛围、出现频率；
- **自动推荐 handraw 风格**：本地关键词打分收敛候选 → DeepSeek 终选；
- 同时自动选 **阶调 T-01~T-40**，生成**触发词**（风格家族 + 该风格 traits + 阶调）；
- 用户可手动换风格、主题色、阶调，或直接编辑触发词。

### 第三阶段：角色人设、主视图与姿态总图

- 为每个角色生成人设（身份卡/关键词/硬特征/记忆点）；
- **主视图**：全身正面标准形象，1024×1024；默认用姿态总图的**正面单视图**重排
  （`CHARACTER_MAIN_FROM_TRIPLE=True`），保证主视图与姿态总图服装完全一致；
- **姿态总图**：1536×1536，一张图出正面/侧面/背面/动作，Pose ControlNet；
  - 三个角度共用同一套服装（只保留一件外层）、同一个角色种子；
  - 背面使用“单人背影”提示与专门负向词，避免正面/双人/换外套；
  - 透明衣料、叠穿、眼镜等冲突写入 negative；
- 用户可单角色重画主视图或姿态总图；
- 参考图保存到 `data/characters/<角色>/默认造型/`。

### 第四阶段：分镜拆解 + 分页选版式

- 拆解为可拍分镜：镜头类型、角色、场景、动作、表情、光线、构图、台词；
- 新增叙事字段：`beat`、`pacing`、`panel_emphasis`、`caption`、`layout_hint`；
- 自动生成页计划：每页 2~6 格，从 SB-001~SB-071 + 原生 WB-* 里选版式；
- 本地动态规划兜底；文本模型方案必须严格覆盖/顺序/格数匹配，且不能过度碎片化
  （单格页 >35%、平均 <2.2 格/页、连续 3 页单格 → 退回本地）；
- 用户可切形态、重新规划、逐页换版式、合成/重拼。

### 第五阶段：出图、拼版、打包

- 每格独立生成（气泡/自检/返修都按格走）；
- 按页计划合成页面（墨线、gutter、页边距、字幕栏、页号）；
- 可选条漫长图（封面/话标题/分格/尾页）；
- 自动自检（100/82/70 分档），不合格定向返修；
- 导出分镜图、原图、分格页、角色设定、提示词、风格/分页文档、PDF、ZIP。

## 四、界面布局

- 左侧：创作流程（1 输入 → 2 分析 → 3 人设与姿态总图 → 4 分镜 → 5 出图与打包）、辅助（运行日志、工程与产物）。
- 顶部：角色/场景/分镜/完成数、演示模式、设置、检查服务。
- 阶段②：
  - 故事理解、内置画风兜底、风格细化建议；
  - **绘制风格卡**：缩略图、编号、中英文风格名、中英文作者名、特征、主题色；
  - **触发词行**：媒介 / 漫画特征 / 阶调；
  - **阶调下拉 + 触发词输入 + 保存按钮**；
  - 自动推荐、浏览全部风格、应用风格、用回内置画风。
- 阶段③：角色卡、人设编辑、主视图/姿态总图预览与重画。
- 阶段④：分镜表格、形态切换（webtoon/page/hybrid）、重新规划、页卡片（版式缩略图、格数、状态、理由、换版式、合成）。
- 阶段⑤：批量生成、单格重画、页面预览、气泡编辑、导出。

## 五、功能详细说明

### 5.1 文本输入与工程

- 新工程生成 id，保存到 `data/projects/<id>.json`；
- 工程记录输出文件夹名，导出时同名目录已存在会自动加后缀；
- 支持载入历史工程继续生成。

### 5.2 内容分析与风格推荐

- 分析结果写入 `summary/plotline/key_points/characters/scenes`；
- 风格候选来自 `stylelib.shortlist_style_ids()`（本地 2-gram/题材词打分）；
- DeepSeek 只在候选里选，不能编造编号；返回不合法则用本地第一名；
- 推荐结果写入 `style_id/style_color_ids/style_rationale/style_tone/style_trigger`；
- 手动选过风格（`style_auto=False`）后重新分析不覆盖，除非点“自动推荐”。

### 5.3 角色人设与参考图

- 人设包含：基本形象、发型发色、服装风格、气质表情、标志性特征、色彩方案；
- `Character.identity_card()` 生成 ≤90 字身份卡，跨格复用；
- **造型锁定**：
  - 只保留第一件外层服装（`CHARACTER_SINGLE_OUTERWEAR=True`）；
  - 去掉“薄纱/透明/透视”描述；
  - 角色没眼镜时，分镜/人设里的“镜片/眼镜/眼罩”会被清理；
  - “眼下淡青影”会改写为“眼周自然肤色”，负向加“眼影/绿色眼影/眼下绿色/彩妆”，
    避免冷绿主题色下被画成绿色眼影；
  - 主视图与姿态总图共用同一个 `character.seed`；
- **姿态总图默认一张多姿态总图**（`CHARACTER_POSE_SIZE=1536²`）：
  - 正面/侧面/背面各自 512×832，同一提示词 + 同一造型 + 专门背面提示；
  - 横向拼成 1216×832，避免“一张图三角度”时背面换大衣；
  - `AUTO_SPLIT_TRIPLE_VIEW` 在旧整张模式下仍可用；
- **负向词**：排除多余人物、额外外套、透明衣物、薄纱、多余肢体、眼镜（角色无眼镜时）。

### 5.4 分镜拆解与校验

每格字段：

| 字段 | 说明 |
| --- | --- |
| shot_type/camera/composition/lighting | 镜头与画面控制 |
| characters/char_sides/char_positions | 出场角色与左右站位 |
| action/expression/focus/gaze | 动作、表情、焦点、视线 |
| dialogue | 台词（说话人/类型/槽位/画外音） |
| beat/pacing/panel_emphasis/caption | 叙事功能/节奏/页面权重/字幕 |
| object_mode | 物件格：物证照/屏幕界面/环境细节 |

校验：可拍性、人数政策（默认 1 人/格）、台词归属、画外音、空镜物件化、版式覆盖等。

### 5.5 分页与版式

- `RENDER_MODE`：`webtoon` / `page` / `hybrid`（默认 hybrid）；
- 版式库：SB-001~SB-071 + WB-001~003；
- 本地 DP：按 7 维适配度、场景连续性、重点格、版式重复、每页代价打分；
- AI 方案：严格校验覆盖/顺序/格数；碎片化方案退回；
- 合成：`ImageOps.pad` 留边（不裁气泡）、墨线 3px、纸色 gutter 28px、页号、字幕栏；
- 单格页/原生条漫直接复用该格成品。

### 5.6 风格与触发词

`stylelib.style_prompt_block()` 输出：

```text
漫画分级特征：{风格家族媒介}；{traits 中真实出现的漫画特征词}；{阶调名}（{阶调说明}）。
视觉语言：{过滤后的正面 traits}。
主题色：{主色，点缀色}。
第1张参考图只用于匹配色彩倾向与整体色调，不取其中的人物、场景、构图、文字或故事。
```

- 默认不写风格名/作者名（Z-Image 会画成标题文字）；
- `HANDRAW_PROMPT_INCLUDE_NAME/AUTHOR` 可打开英文激活（有文字风险）；
- 界面手改触发词后，**原样**作为「漫画分级特征」；留空则自动组合；
- 相关字段：`style_tone`、`style_trigger`、`style_medium`、`style_comic_features`。

### 5.7 图像生成与风格工作流

| 工作流 | 用途 | 说明 |
| --- | --- | --- |
| `image_z_image_turbo_int8` | 基础文生图 | 无参考图/兜底 |
| `..._style_color` | **默认风格链路** | 出图后 ColorTransfer 只迁色彩（强度 0.55） |
| `..._style_ref` | 实验性 Omni 参考图 | 3 路（1 画风 + 2 角色），需 Omni 权重，否则抄内容 |
| `..._style_img2img` | 图生图兜底 | 低 denoise，保留参考构图 |

- 参考图上传前统一处理：style_color 等比缩到 768（不填灰边，避免污染 ColorTransfer）；
  Omni 才填 768²，防多图尺寸不一致报错；
- 工作流只有 1 路图像输入时只送 1 张（色彩迁移只取画风）；
- 用户显式选择主题色时，ColorTransfer 强度降到 `COMFY_COLOR_TRANSFER_THEME_STRENGTH`
  （默认 0），否则主题色会被画风参考图的色分布盖掉；
- 失败/OOM 自动降档重试；结果按提示词+种子+参考图缓存。

### 5.8 负面条件（本轮新增）

- 四个工作流都已把 `KSampler.negative` 接到 `CLIPTextEncode`（标题「负面提示词」），
  不再是 `ConditioningZeroOut`；
- 负向词按类型组合：
  - 镜头：低质量/畸形/多格/画框/文字 + 多余人 + 程序气泡；
  - 主视图：多余人/额外外套/透明衣料/眼镜（角色无眼镜时）；
  - 姿态总图：三角度服装不一致/透明衣料/多余肢体；
  - 背面：双人/正面人物/镜像/背面换大衣；
  - 风格：写实风格压卡通，二次元压照片，3D 压平面简笔；
- 生效条件：`COMFY_NEGATIVE_ENABLED=True`、工作流有 negative 文本节点、`COMFY_CFG>1`；
- 当前 `COMFY_CFG=1.4`（官方推荐 1；1.4 是负面词生效与画质之间的折中，过高会失真）。

### 5.9 气泡与文字

- 色彩迁移会染色空白气泡 → 该链路**程序画气泡**；
- 旁白多条合并成 1 条（≤56 字），旁白宽度 52%，气泡宽度 46%；
- 分格页文字再乘 0.92；不再默认要求模型留白（避免半格刷成空地）；
- 气泡程序绘制时用细节密度/肤色网格避开人脸；旁白与气泡不重叠。

### 5.10 自检与返修

- 每格 100 分制；通过 82，可交付 70；
- 检查：人数、参考图、气泡定位/数量、空镜人脸、肢解、白色边框、文字溢出等；
- 不合格按问题定向返修最多 2 次，保留最高分版本；

### 5.11 清空、重排与实时刷新

- **清空图片不碰文本**：支持按单格/整页/单个角色/全部图片清空；
  只重置路径、状态、气泡计划与质量标记，小说/人设/分镜/页版式都保留；
- 风格卡有「应用风格并清空旧图」，换风格调试时一次性作废旧图；
- **重新规划版式不自动合成旧图**：旧图属于上一版风格/版式，页面先显示
  “待生成”；分格画幅从当前 `page.cells` 计算，不再沿用旧 `shot.panel_size`；
- 批量/单格生成每完成一格，前端立即刷新当前页面的分镜卡/页图，不等整批结束；
- 阶调/主题色在「应用风格」时保留；只有切换风格才自动重选阶调。
- 分格页在拼版时检查画幅比例，必要时留边并提示。

### 5.11 导出结构

```text
outputs/<名称>/
├── 00_输入/            原文、工程信息
├── 01_分析/            分析结果、绘制风格.md/.json（含阶调/触发词）
├── 02_角色/            人设卡、主视图、姿态总图、单视图
├── 03_分镜/            分镜脚本、台词表、分页与版式.md/.json
├── 04_提示词/          逐格提示词.jsonl（每格最新一版）、气泡计划
├── 05_分镜图/          成品、原图/、页面/
├── 06_条漫/            条漫长图
├── 07_阅读/            封面、PDF
├── 08_回溯/            质量报告
└── 09_清单/            manifest
```

## 六、工作流与参数

### 6.1 工作流节点（默认 style_color）

```text
UNETLoader(Z-Image-Turbo int8)
  → ModelSamplingAuraFlow → KSampler
CLIPLoader(qwen_3_4b) → CLIPTextEncode(正) / CLIPTextEncode(负)
EmptySD3LatentImage → KSampler → VAEDecode → ColorTransfer(画风缩略图) → SaveImage
```

### 6.2 默认参数

| 参数 | 值 |
| --- | --- |
| 步数 | 8 |
| cfg | 1.4（`COMFY_CFG`） |
| 采样器 | res_multistep / simple |
| 色彩迁移 | reinhard_lab，强度 0.55 |
| 参考图尺寸 | style_color 等比 ≤768；Omni 768² |
| 分镜格 | 448~1280 边长，按页面格子计算 |
| 角色主视图 | 1024×1024 |
| 姿态总图 | 1536×1536 |

### 6.3 负面条件与 cfg 的取舍

Z-Image-Turbo 官方模板推荐 cfg=1，此时 negative 条件在数学上被忽略；ComfyUI 官方
issue 也确认“高 cfg 才会失真”。本项目为了满足“负面条件必须存在且尽量生效”：

- 工作流保留 negative 节点，文本始终写入；
- 默认 cfg=1.4，让负向词开始起作用；
- 若发现画面过曝/线条变硬，把 `COMFY_CFG` 调到 1.0（负向词失效）或 1.2；
- 若换成非蒸馏 Z-Image，可把 cfg 调到 3~5，负向词效果更明显。

## 七、配置项（与使用相关）

| 配置 | 作用 |
| --- | --- |
| `RENDER_MODE` | webtoon / page / hybrid |
| `HANDRAW_STYLE_AUTO` / `HANDRAW_STYLE_REC_LLM` | 自动推荐 / 文本模型终选 |
| `HANDRAW_PROMPT_TRIGGER` | 是否注入「漫画分级特征」 |
| `HANDRAW_TONE_ENABLED` / `HANDRAW_TONE_DEFAULT` | 自动阶调 / 锁定阶调 |
| `HANDRAW_PROMPT_INCLUDE_NAME` / `..._AUTHOR` | 是否写英文风格名/作者名（默认关） |
| `CHARACTER_SINGLE_OUTERWEAR` | 只保留一件外层服装 |
| `CHARACTER_POSE_WORKFLOW_NAME` | 姿态总图 Pose ControlNet 工作流 |
| `CHARACTER_POSE_SIZE` / `CHARACTER_POSE_WORKFLOW_NAME` | 姿态总图尺寸/Pose 工作流 |
| `CHARACTER_SAME_SEED` | 主视图/姿态总图共用角色种子 |
| `COMFY_CFG` / `COMFY_NEGATIVE_ENABLED` | 负面条件 cfg 与开关 |
| `BUBBLE_RESERVE_PAGE_ENABLED` | 分格页是否要求模型留白（默认关） |

完整配置见 `config.py` 与 `README.md`。

## 八、非功能要求

- **显存**：8GB 可跑；批量生成单张串行，OOM 降档；不要同时开其他大模型。
- **性能**：单张 20~40s；角色 3 视图约 3 张；一话 15 格约 5~8 分钟。
- **可靠性**：单格失败不中断整批；工程/提示词/质量报告落盘；可断点续跑。
- **安全**：文本/图像密钥只在本机 `config.py` 或设置中保存；ComfyUI 默认本地无鉴权。
- **可维护**：规则在 `rules/`，提示词在 `prompts/`，风格资产只读引用 handraw-style。

## 九、验收标准

1. `selftest.py` 全绿（风格库/版式/工作流/气泡/导出）。
2. 新建工程能走完五阶段并导出 1 话成品（分镜图 + 分格页 + 条漫 + PDF）。
3. 风格卡能自动推荐/手动换风格，并显示阶调与触发词；手改触发词能进入实际提示词；
   风格名与参考作者默认中文主显示、英文原名保留，不能只显示英文。
4. 分页覆盖所有分镜，无重无漏；页面能合成；AI 碎片化方案会退回。
5. 工作流 negative 节点存在且 cfg>1 时负向词写入生效；关闭开关后不写入。
6. 角色主视图与姿态总图外层服装一致；姿态总图不出现透明衣料/无关眼镜（无眼镜角色）。
7. 气泡不遮脸、旁白不堆叠；分格页不出现半格空白。
8. 导出 `04_提示词/逐格提示词.jsonl` 每格含「漫画分级特征」且只留最新一版。

## 十、已知限制

- **角色脸跨格一致性**仍以身份卡 + 同种子为主；没有角色 LoRA/ReferenceLatent 时，
  不同格的脸会有漂移。当前不训练 LoRA，跨格一致靠身份锁 + 固定种子 + 服装/发型/眼睛负向词。
- `style_ref`（Z-Image Omni）在基础 Turbo 权重下会抄参考图内容，默认不启用。
- 负面条件在 cfg=1 时无效；cfg=1.4 是折中，极端风格可能需要回调。
- 中文文字/招牌仍可能偶发乱码；已用负向词压制，但不能保证 100%。
- 8GB 显存不建议开多参考图/大尺寸批量并发生成。
