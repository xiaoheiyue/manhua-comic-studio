# 竖屏条漫与分镜页叙事规则（含 handraw-style 版式）
> 用途：作为「小说 → 条漫 / 分镜页」AI 流水线的分镜生成与校验依据。每条规则都写成可落地的检查项/约束，并标注来源。
> 来源分级：**【官方】**平台规定；**【工业】**平台教程/工具厂商的量化经验（可调参，非硬规定）；**【教材】**漫画/影视理论。
>
> **本项目实际执行的分镜/出图规则在 [rules/](../rules) 目录**：本文负责"条漫/页漫两种形态的叙事与排版"，
> `rules/07_风格与分镜版式.md` 负责 handraw-style 画风、阶调、触发词与 SB-* 版式选择，
> `rules/02_分镜与镜头规则.md` 负责"这一格能不能拍"、`rules/03_提示词工程规则.md` 负责"怎么写进模型"。
> 两者冲突时，以 `rules/` 为准。

## 0. 适用范围：条漫 / 分镜页 / handraw 版式（2026-10 起）

本文不再只描述"一格一张、竖屏无缝长条"。本项目现在有三种形态：

| 形态 | `RENDER_MODE` | 规则来源 | 适用 |
| --- | --- | --- | --- |
| 原条漫 | `webtoon` | 本文 §1–§6 的竖屏规则 + WB-001/002/003 | 强情绪、强冲击、手机一路下滑 |
| 分镜页 | `page` | 本文 §1 的页漫改写 + handraw SB-001–SB-071 | 对白密集、信息量大、日常叙事 |
| 混排 | `hybrid`（默认） | 两者并用，按内容自动分流 | 大多数连载 |

**handraw-style 与本文章节的关系**：

- 画风：365 种（`FA-001–FI-034`）+ 36 主题色（`C-01–C-36`）+ 16 阶调（`T-01–T-16`）；
- 版式：74 个漫画版式（SB-001–SB-071 + 原生 WB-001/002/003），每个版式有格数、几何、
  7 维适配度（对白/动作/情绪/建立/蒙太奇/悬疑/喜剧）；
- 选择：分析出 `beat / pacing / panel_emphasis / caption` → 本地 DP 或 AI 方案 →
  严格校验（覆盖全部格子、顺序不乱、格数匹配、单格页不过量）；
- 本文的 R1–R24 仍然适用于**每一格**；分镜页只是把这些格按 SB-* 几何组织到页面上，
  额外增加"页"这一层的节奏（翻页停顿、页首/页尾钩子、跨页重点格）。

> 版式数据：`rules/data/storyboard_layouts.json`（可热改）。
> 版式与触发词细节：[rules/07_风格与分镜版式.md](../rules/07_风格与分镜版式.md)。

## 1. 竖屏条漫 vs 传统页漫：哪些规则要改写

**【官方】画布与切图**
- 宽度固定、高度自由：LINE WEBTOON 投稿规范为**单图宽 <800px、高 <1280px、单图 <2MB、单集总和 <20MB**（[投稿规范](https://www.webtoons.com/zh-hant/challenge/operationalPolicies)）；CLIP STUDIO 也把「多张高度 <1280px 的图纵向排列」定义为条漫的发布形态（[CSP 教程](https://www.clipstudio.net/painting/archives/157034)）。
- **流水线约束**：整集先在一张长画布上排版，最后**只在场景转换处/分镜间隙/刻意留白处切割**，绝不在格子中间切——读者会把刀口误读为加载错误（[StoriesToon / CSP Tips](https://tips.clip-studio.com/zh-tw/articles/17461)）。
- 推荐单集总高 6000–12000px（约 50–80 格），<4000px 像预告、>14000px 中段流失（【工业】[Comistitch](https://comistitch.com/blog/webtoon-pacing-and-cliffhanger-techniques/)）。

**【教材+工业】页漫规则如何改写**

| 页漫规则 | 条漫改写 |
|---|---|
| 一页 5–8 格、不对称网格、读者扫视整页 | **一格一个 beat**，单列纵向；同屏通常只看到 1–2 格（[Comistitch](https://comistitch.com/blog/webtoon-vertical-scroll-paneling-guide/)） |
| 翻页（page flip）制造停顿 | **留白/格间距（gutter）即时间**：空白越大 = 停顿越久（[CSP](https://www.clipstudio.net/painting/archives/157034)） |
| 断行靠页边界 | **断点靠 scroll-fold**：手机屏每 600–800px 结束一次，钩子要压在这个节拍上 |
| 页内 Z 字动线 | 竖向单列动线，格内仍保留左→右、上→下的读数顺序（[Steve Ellis / CSP](https://www.clipstudio.net/painting/archives/168001)） |
| 文字量与页漫相当 | 条漫**文字量要更少**、画风更简、必须彩色（[CSP](https://www.clipstudio.net/painting/archives/157034)） |

**【工业】量化基线（可直接做默认参数）**：webtoon 每屏 3–5 格、每格对白 10–20 词、2–4 个视觉动作；单格超过 ~30 词即「字压图」（[Redmoon](https://redmooncalculators.com/blog/comic-page-pacing-density/)）。gutter 默认：动作 100–150px、对白 200–300px、场景切换 400–600px、悬念前 600–800px（[Comistitch](https://comistitch.com/blog/webtoon-vertical-scroll-paneling-guide/)）。

## 2. 格子衔接：McCloud 六种转场的用法与配比

**【教材】**McCloud《理解漫画》把格间关系分为六类：moment-to-moment（时刻到时刻）、action-to-action（动作到动作）、subject-to-subject（主体到主体）、scene-to-scene（场景到场景）、aspect-to-aspect（侧面到侧面）、non-sequitur（无关）。他的统计显示美式主流漫画高度依赖 action-to-action，而日漫大量使用 aspect-to-aspect 来营造氛围与"此时此地"（[Image & Narrative 对其分类的复现研究](https://www.imageandnarrative.be/index.php/imagenarrative/article/download/128/99/0)）。

**【工业】条漫配比建议（一集内，可按题材 ±10% 调整）**
- action-to-action 40–50%（推进主干，条漫唯一能连续使用的转场）
- subject-to-subject 20–25%（对话/反应切人）
- aspect-to-aspect 10–15%（环境、手部、道具特写；日漫式氛围，条漫竖向天然适合）
- scene-to-scene 5–10%（必须配建立镜头）
- moment-to-moment 5–10%（仅用于关键动作的分解，**连续不超过 4 格**）
- non-sequitur ≤5%（默认禁用；仅允许用于梦境/心理蒙太奇，且需色调或边框做信号）

**【可执行约束】**
- 每 4–6 格必须发生一次**转场类型变化**，禁止整段同类型堆叠。
- 禁止连续 ≥3 格 aspect-to-aspect 而无事件推进；
- 禁止连续 ≥3 格 subject-to-subject 而主体不变（= 无意义图片堆叠）。
- 每次 scene-to-scene 前后必须满足：上一场景有收束格（情绪落点）、新场景首格是建立镜头。
- 「无厘头堆叠」判据：**若删掉某格，读者对因果的理解毫无变化 → 该格无效**，标记为氛围格，每场景氛围格占比 ≤30%。

## 3. 叙事完整性：章节与场景结构

**【教材+工业】双层模板**
- **整集（起承转合 / 三幕压缩）**：钩子（前 10–15%，最好 3 格内出冲突）→ 上升（~60%，目标-阻碍反复）→ 高潮/反转（~20%）→ 悬念落点（**必须在总高最后 20% 内**，前接 600–800px 空白格，[Comistitch](https://comistitch.com/blog/webtoon-pacing-and-cliffhanger-techniques/)）。
- **单场景四拍**：建立（时间/地点/人物位置）→ 目标（人物想要什么）→ 冲突（谁/什么阻碍）→ 转折（"但是/因此"）。场景之间必须是**因果链（因此/但是）**，不许"然后…然后…"。

**【可执行约束】**
- 情节点覆盖率 = 100%：源小说每个情节点（beat）必须映射到 ≥1 格，且每格字段 `plot_beat_id` 非空。
- 因果链检查：除首格外，每格须有 `cause_panel_id` 或 `effect_of`；孤儿格报警。
- 禁止因果断裂：跨场景必须有一格"桥接"（旁白/道具/视线/建立镜头）解释时空跳转。
- 章末悬念禁止出现在 60–70% 深度（"提前泄底"是最典型的流失原因）。
- **分镜页额外约束**：每页 2–6 格；页首格负责"进入"（建立/承接），页尾格负责
  "转折/钩子"；翻页前留 400–600px 的停顿（gutter/留白）；满版或跨页只给
  `panel_emphasis="splash"` 的重点格，一页最多 1 个；单格页只留给章首/章末/大反转。
- **混排约束**：同一场景内不要条漫长格与分镜页来回跳；用"场景切换/时间跳转"作为
  形态切换点，避免阅读节奏碎裂。

## 4. 旁白与对话的分工与配比

**【工业+教材】分工**
- **旁白（narration box，方框无尾）**只承担三件事：①时空定位（"三日后·雨夜"）②视角人物内心 ③因果桥接（画面无法呈现的省略）。**不得复述画面已经可见的信息**（"他愤怒地举起拳头"配一张举拳图 = 对话解释画面）。旁白框层级低于气泡：无指向、置于格顶或格边（[O_kids #7](https://tips.clip-studio.com/zh-cn/articles/10886)）。
- **对话（气泡）**承担：关系、态度、信息交换、冲突升级。形式要与语气匹配：普通对白椭圆、心声云形、旁白方框、低语虚线、喊叫锯齿、破碎气泡=虚弱（同上）。

**【可执行约束（量化）】**
- 单格对白总字数 ≤20（中文 ≤20 字），单气泡 ≤15 字、≤2 行，单格气泡数 ≤3；超过即拆格。
- 旁白 : 对话 ≈ 3:7（对白驱动）～4:6（心理悬疑向），旁白连续 ≤2 格。
- **连续有台词格 ≤3，第 4 格前必须插入反应格（听者特写）或无字格**；连续 5 格纯对白 = 红旗（[Comistitch 保留率信号](https://comistitch.com/blog/webtoon-pacing-and-cliffhanger-techniques/)）。
- 气泡不得覆盖人脸（尤其眼、嘴）与关键道具；气泡阅读顺序：格内自上而下、右→左（对话队列须显式编号 bubble_order）。
- 字号在 800px 宽画布上保证手机 100% 缩放可读——需要捏合才能读即判失败（[StoriesToon](https://tips.clip-studio.com/zh-tw/articles/17461)）。

## 5. 镜头语言与节奏

**【工业+影视连续性规则】**
- 标准序列：**建立镜头（远景/全景）→ 中景 → 特写**；同一场景内不得连续 3 格同景别；特写占比约 ≤30%（多了变"情绪通货膨胀"）。
- **重复同一构图**只允许两种用途：①蓄势（同构图 ×2 后接巨变格，做"顿"）②对位（前后呼应，如第一集与最后一集）。禁止无意义的同构图连排。
- **静默格（无台词格）**：每个场景至少 1 格；情绪转折点后必须跟 1 格静默反应格。
- **留白格 / breath panel**：每 8–12 格至少 1 个 ≥400px 的空白或纯氛围格，用于情绪泄压。（cliffhanger 前的空白属另一类，见 §3。）
- **连续性（continuity）**：相邻格遵守 180° 轴线（对话双方屏幕朝向不互换）、30° 机位差（禁止同机位同景别相邻，避免"跳帧"感）、视线匹配（看向画外的目光要指向下一格主体）。跳轴时须用中性镜头（正面/背面）或运动镜头过渡（古典好莱坞连续性剪辑通则，[CCEA 教材](https://ccea.org.uk/downloads/docs/Support/Fact%20File:%20AS/2019/AS%20MIA%20Fact%20File:%20Classical%20Hollywood%20Style.pdf)）。台词前后一致的角色位置（左/右）必须锁定在同一 side 字段。

**【可执行约束】**
- 每场景首格 `shot ∈ {wide, full, establishing}`；场景内每 ≤6 格至少出现一次中景或远景做空间锚点。
- 禁止相邻两格 `shot` 与 `camera_angle` 完全相同（除标记为 intentional_mirror 的蓄势/对位对）。
- 动作序列拆分上限：一个"拳挥出→命中"最多 3 格 moment-to-moment，之后必须切主体或侧面。

## 6. 阅读引导：格子高度=时间（条漫）/ 格子面积=权重（分镜页）

**【教材+工业】**
- 动线：整条条漫是**竖向单列**；格内仍是左→右、上→下；每格只能有**一个视觉焦点**，用构图/明暗/景深把视线推向下一格（[Steve Ellis](https://www.clipstudio.net/painting/archives/168001)；[CSP 条漫特征](https://www.clipstudio.net/painting/archives/157034)）。
- 纵向格（tall panel）表现高耸/坠落/深情绪，**减慢阅读速度**；横向宽格（wide）表现landscape/平静，**加快阅读**（[O_kids 分格类型表](https://tips.clip-studio.com/zh-cn/articles/10886)）。
- 用角色与台词的**纵向排布**做演出：先台词后角色 = 人物沉浸在思考中（[CSP](https://www.clipstudio.net/painting/archives/157034)）。

**【可执行约束】**（设基准格高 H≈450–550px，800px 宽）
| 用途 | 格高 | 目的 |
|---|---|---|
| 动作/快节奏 | 0.4–0.6H，gutter 100–150px | 压缩时间 |
| 常规对白 | 0.8–1.0H，gutter 200–300px | 稳定读数 |
| 情绪/冲击/反转 | 1.2–2H，gutter 400–500px | 拉长时间 |
| 场景转换 | 任意，gutter 400–600px | 空间重置 |
| 呼吸/悬念前 | gutter 600–800px | 强制停顿 |
- 格高方差检查：连续 8 格高度差 <15% → 节奏单调，报警。
- 严禁"一格塞两个动作"（action_beats_per_panel > 1 → 拆格，[Redmoon](https://redmooncalculators.com/blog/comic-page-pacing-density/)）。
- **分镜页**：格子**面积=视觉权重**。大格（满版/跨格/居中大格）给重点、情绪、空间揭示；
  小格给快切信息、反应、连续动作。阅读顺序由几何决定（Z 字/网格/纵向/居中爆发），
  同一页不要混用两种动线；对白格优先放在页面上半部或视线起点，页尾格留转折。
- **分镜页的 gutter**：默认 28px 纸色 gutter + 3px 墨线；重点格可加宽到 40–56px，
  但同一页内保持统一，否则读者会误读为"漏了一格"。

## 7. 新手错误清单（对照体检表）

1. **镜头跳轴**：对话双方左右互换、视线不对接 → 检查 side/axis 字段。
2. **同一动作重复画**：相邻格内容语义重复（用图像相似度 + 描述文本相似度双阈值识别）。
3. **对话解释画面**：旁白/台词复述画面已给出的事实。
4. **时空不明**：新场景无建立镜头、无时间地点标注。
5. **情绪无铺垫**：高潮/崩溃格前缺少 ≥2 格的蓄势与 1 格静默格。
6. **格子高度均一**：全篇等宽等高 → 机械感（保留曲线把"面板宽度/高度方差过低"列为三大红旗之二）。
7. **纯对白连排**：3 格黄旗、5 格红旗，无反应格与听者特写。
8. **悬念放太早**：反转落在 60–70% 深度。
9. **文字过载**：单格 >30 词 / 气泡压脸 / 手机需缩放。
10. **切图切坏分镜**：在格子中央切割上传图。
11. **景别单薄**：全篇近景，缺建立镜头与远景空间感。
12. **无意义的 non-sequitur**：读者读不出格与格的因果关系。

## 8. 可直接写进提示词的约束清单

- 一格只讲一个 beat；一格只画一个动作、一个焦点。
- 每条输出必须给出：`scene_id / shot / camera_angle / transition_type / panel_height / gutter / dialogue / narration / silent`。
- 换场景时，首格必须是建立镜头，并给出时间与地点信息。
- 每个场景至少包含一格无台词格；每 8–12 格至少一格留白呼吸格。
- 每 4–6 格必须改变一次转场类型；连续同类转场不得超过 4 格。
- 单格对白 ≤20 字、≤3 个气泡；单气泡 ≤15 字、≤2 行；气泡不得遮住人脸。
- 旁白只用于交代时间地点、人物内心、因果桥接；禁止复述画面可见内容。
- 连续有台词格不超过 3 格，之后插入反应格或静默格。
- 同一场景内不得连续 3 格使用同一景别；相邻格不得同机位同景别。
- 保持 180° 轴线与人物屏幕朝向一致；换轴必须用中性镜头或运动过渡。
- 动作格高 0.4–0.6 倍基准格高，对白格 0.8–1.0，情绪/反转格 1.2–2。
- 章节结构：3 格内出钩子 → 上升 → 反转 → 悬念落在结尾最后 20%。
- 高潮前必须有两格以上蓄势与一格静默格，禁止情绪空降。
- 删除任何「删掉也不影响因果理解」的格子，或明确标注为氛围格且占比 ≤30%。
- 忠于原著：源文本每个情节点至少被一格覆盖，不得合并或跳过关键转折。
- **画风触发词**：每格正向提示词最前面注入「漫画分级特征：风格家族媒介；漫画特征词；
  阶调」+「视觉语言：…」+「主题色：…」；分格页再补该格的横向/纵向/方形构图。
- **负面条件**：正向提示词只写"要什么"；"不要文字/多格/画框/多余人物/透明衣物"等
  必须放在独立的 negative 节点（`COMFY_CFG>1` 才生效），不要写进正向。
- **分格页提示词**：必须带当前格的 `panel_orientation`（wide/tall/square）和
  `panel_role`（main/normal/inset），否则模型会按整幅条漫构图，拼页时被裁。
- **角色姿态总图**：不属于分镜格；姿态总图禁止多格负向词，必须用"三角度服装一致/单人背影/
  不透明面料"专用负向词，避免把并排三角度误判为多格漫画。

## 9. 用于自动校验的规则（可程序化检查）

设每格 JSON：`{id, scene_id, time, place, shot, angle, transition_type, height, gutter_before, dialogue:[{char,text}], narration, plot_beat_id, cause_of, action_beats, chars:[{name,side,screen_dir,pose,outfit}]}`。

| # | 条件 | 报警 |
|---|---|---|
| R1 | `p[i].scene_id != p[i+1].scene_id` 且 `p[i+1].shot ∉ {wide,full,establishing}` | `scene_change_without_establishing` |
| R2 | 同一 scene 内连续 3 格 `shot` 相同 | `shot_monotony` |
| R3 | `p[i].shot == p[i+1].shot && p[i].angle == p[i+1].angle` 且未标 `intentional_mirror` | `jump_cut_30deg` |
| R4 | 对白/旁白队列中同一角色 `side` 在相邻 4 格内翻转且无中性镜头 | `axis_break_180` |
| R5 | 连续 `transition_type` 相同且 run_length > 4（moment-to-moment）/ > 3（aspect-to-aspect、subject-to-subject） | `transition_stack` |
| R6 | 滑动窗口 6 格内 `transition_type` 去重数 == 1 | `no_transition_variation` |
| R7 | 连续 `has_dialogue == true` 的格数 ≥ 4 | `dialogue_clump` |
| R8 | `sum(len(d.text)) > 20` 或 `len(dialogue) > 3` 或任一气泡 `>15 字 / >2 行` | `lettering_overload` |
| R9 | 气泡包围盒与 `face_bbox`（眼/嘴）或关键道具 bbox 相交 | `bubble_occludes_face` |
| R10 | `narration` 文本与画面 caption/描述语义相似度 > 0.8 | `caption_redundant_with_art` |
| R11 | scene 内 `silent == true` 的格数 == 0 | `no_silent_panel` |
| R12 | 滑动窗口 12 格内 `height >= 400px 的空白格` 数 == 0 | `missing_breath_panel` |
| R13 | scene 内 `sum(action_beats) / panel_count > 1.0` | `overloaded_action_per_panel` |
| R14 | 连续 8 格 `height` 极差 / H < 0.15 | `flat_rhythm` |
| R15 | `p[i].plot_beat_id == null` 或源文本 beat 集合未被覆盖 | `plot_beat_uncovered` |
| R16 | `p[i].cause_of` 为空且 `i != 0` 且 `transition_type != scene-to-scene` | `orphan_panel` |
| R17 | 章节最后 20% 高度内不存在 `is_cliffhanger == true` 的格 | `cliffhanger_misplaced` |
| R18 | cliffhanger 格之前的 `gutter_before < 600px` | `weak_cliffhanger_pause` |
| R19 | 相邻两格角色 `pose/outfit/expression` 描述相似度 > 0.85 且动作语义相同 | `duplicate_action_panel` |
| R20 | 相邻两格 scene 不同但 `time`/`place` 字段为空或未变 | `missing_scene_anchor` |
| R21 | 任一格 `chars[].outfit` 与同 scene 首格不一致且未标 `outfit_change = true` | `costume_drift` |
| R22 | 单集总高 <4000px 或 >14000px；任一切图高度 >1280px 或宽 >800px；切图刀口落在某格 `bbox` 内部 | `publish_spec_violation` |
| R23 | 同场景内角色 `screen_dir`（面向左/右）不一致 | `eyeline_mismatch` |
| R24 | 章节第 1–3 格内未出现冲突/钩子事件 | `weak_opening_hook` |
| R25 | 页计划没有覆盖全部格子（漏格/重复格/顺序乱） | `page_coverage_broken` |
| R26 | 某页 `layout.panels` 与该页实际格数不一致 | `page_layout_mismatch` |
| R27 | 单页格数 <1 或 >6 | `page_panel_count` |
| R28 | 单格页占比 >35%（整话 ≥8 格时） | `page_fragmented` |
| R29 | 连续 3 页都是单格页 | `page_single_run` |
| R30 | 页面格子宽高比 <0.32 或 >2.8 | `page_cell_extreme` |

**实现建议**：R1–R14、R19–R24 纯结构化字段即可判；R10、R19 需文本/图像嵌入相似度；
R25–R30 由 `comicgen/pagelayout.py` 的 `pages_valid()/summary()` 直接判。
所有报警分为 `error`（R1、R5、R8、R15、R22、R25、R26）与 `warn`（其余），
error 触发重新生成该格/该页或退回本地规划，warn 仅在报告中提示。
