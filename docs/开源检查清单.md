## 三、发布后前两周要盯的指标

| 指标 | 健康值 | 不健康说明 |
|---|---|---|
| 成功安装人数 | ≥ 10 | 安装门槛太高，优先做一键检查脚本 |
| 新 Issue 数 | ≥ 5 | 没人用，或没人愿意反馈 |
| 外部 PR | ≥ 1 | 贡献门槛高，补 good first issue |
| 群消息中"跑不起来"占比 | < 50% | 文档没写清，或模型清单不够具体 |
