# 社区

这个项目的社区只有一条原则：**GitHub 是事实源，群是聊天室。**

## 三个入口

| 入口 | 用来做什么 | 响应预期 |
|---|---|---|
| [Issues](https://github.com/your-name/manhua-comic-studio/issues) | 报 bug、提需求、认领任务 | 7 天内 |
| [Discussions](https://github.com/your-name/manhua-comic-studio/discussions) | 用法讨论、作品展示、想法 | 随缘 |
| 内测群（QQ / 微信） | 快速问一句、看别人怎么用、约内测 | 工作日晚上 |

> 群二维码 / 群号请由维护者在发布时补充；不要相信任何非本仓库给出的收费群。

## 提问的正确姿势

1. 先说你在做什么（什么小说、多少字、想要条漫还是分页）。
2. 贴 `python selftest.py` 的结果（一行"全部自检通过"就够）。
3. 贴报错原文 + 日志片段（**删掉密钥**）。
4. 说清楚卡在哪一步（第几阶段、第几格）。

坏问题："出图不对怎么办？"
好问题："第 5 步第 3 格，双人对话被拆成两个单人，但我想保留同框；`AUTO_SPLIT_MULTI_SHOT` 关掉后又撞脸，有没有折中配置？"

## 群规（简版）

- 不发广告、不拉人、不卖课。
- 不要求维护者秒回；催单直接忽略。
- 报 bug 请去 Issue，群里只做"这事是不是 bug"的初判。
- 可以发自己的作品，但请说明用了哪些素材、是否有版权。
