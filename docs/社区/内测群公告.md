# 内测群公告

> 复制下面这段，发在群公告 / 置顶。

---

**【漫画生成器 · 内测群】**

这是一个本地跑的「小说 → 条漫」工具，作者一个人写的，现在开放 30 个内测名额。

**它能做什么**
上传一篇小说 → 自动分析角色/场景 → 生成人设 → 拆分镜 → 出图 → 拼页 → 导出条漫长图 / PDF。

**它不能做什么（先看这条，避免预期错位）**
- 不能稳定保持同一张脸（近景还行，全景会漂）。
- 不是一键商用平台，没有账号、没有云端，所有东西跑在你自己电脑上。
- 需要 8GB 以上显存的 N 卡 + 本地 ComfyUI + 十几 GB 模型。

**进群前请确认**
1. 你有 Windows 电脑 + 独显（或愿意用 CPU 慢跑试试）。
2. 你能接受"装环境可能要折腾 1 小时"。
3. 你愿意在出问题时贴日志，而不是只问"为什么不行"。

**群里能问**
- 装不上、跑不通、报错看不懂。
- 参数怎么调、分镜为什么这样拆。
- 想加什么功能，先在这里说，我去开 Issue。

**群里不问**
- "能不能自动变现"、"能不能一键生成 100 话"。
- 与项目无关的 AI 工具推荐。

**提问模板（复制粘贴）**
```
系统：Win11 / RTX 4060 8G
跑到第几步：第 5 步第 3 格
现象：报错 CUDA out of memory
已试过：调小 WEBTOON_PANEL_SIZE_MAP，仍然报错
selftest：全绿
日志：（贴 20 行，删掉 key）
```

**两个约定**
- 报 bug 请最终落到 GitHub Issue，群里解决完也请补一条，方便别人搜到。
- 不许发广告、拉人、卖课；发自己作品可以，请注明素材来源。

群文件里放了：安装清单、模型下载地址、常见报错对照表。
