## 二、简介（短版，直接粘贴）

```text
把一篇小说丢进去，自动变成能往下滑的彩色条漫。

全程本地跑：ComfyUI + Z-Image-Turbo / Qwen-Image-2.1，小说和图片都不上传，不按张收费。
流程：分析角色场景 → 人设三视图 → 拆分镜 → 25 格 → 拼页 → 气泡填字 → 条漫长图 / PDF。
内置 365 种画风、74 种漫画分页版式，气泡会避开人脸，每格出图后自检，不合格自动重画。

开源（Apache-2.0），代码和安装说明：
https://github.com/xiaoheiyue/manhua-comic-studio

门槛说清楚：需要 8G 以上显存的 N 卡 + 本地 ComfyUI + 十几 G 模型；
同一张脸还不能稳定保持，全景会漂。这不是「一键商用」，是一个还在长的本地工作室。

演示文本用的是公版《孔乙己》。视频含 AI 生成内容，仅供学习交流。
```

## 三、简介（长版，放专栏 / 评论区置顶）

```text
【这是什么】
一个跑在自己电脑上的「小说 → 漫画」流水线。不是套壳网页，也不是按张收费的 API：
图像推理走本地 ComfyUI（Z-Image-Turbo / Qwen-Image-2.1），只有文本分析走可替换的 OpenAI 兼容接口。

【一条流水线做了什么】
小说 → 精修（核心任务 / 视觉锚点 / 连续故事板）→ 角色与场景分析 → 人设三视图
→ 分镜拆解（镜头、节奏、气泡位）→ 25 格场景分镜 → 拼页选版式 → 气泡填字
→ 条漫长图 / 分页 PDF / ZIP。

【几个自己觉得有用的点】
· 365 种 handraw 画风 + 36 主题色，按故事气质自动推荐
· 74 种漫画分页版式，按内容自动编页，不是一页一格
· 气泡先生成空白气泡再定位填字，尽量不压脸
· 每格出图后检查白边 / 文字溢出 / 多余气泡，低了自动重画
· 有离线自检脚本，不花 token、不需要 GPU 也能验证全链路

【短板，先讲清楚】
· 同一张脸跨格不稳定，8G 显存下这是硬限制
· 要自己装 ComfyUI 和十几 G 模型，装环境可能要折腾
· Windows 优先，Mac/Linux 能跑但要自己起 ComfyUI
· 不是 SaaS，没有账号、计费、多租户

【开源】
Apache-2.0：https://github.com/xiaoheiyue/manhua-comic-studio
安装：装 uv → uv venv .venv（自动下载 Python 3.12）→ uv pip install -r requirements.txt

【用的素材】
演示文本为公版《孔乙己》；画风库 handraw-style 已按其许可署名。
视频含 AI 生成内容，仅供学习交流，请勿用于侵权用途。
```

## 五、创作声明 / 分区

- **创作声明**：优先选「含 AI 生成内容」；没有这个选项就选「自制」，并在简介里注明 AI 生成。
  国内自 2025-09 起要求对 AI 生成合成内容做标识，别省这一步。
- **分区**：面向漫画创作者选「绘画」；面向开发者选「科技 → 软件应用」。二选一看你想吸引谁。
- **封面**：别用纯 UI 截图。用一张成品漫画页 + 大字「小说 → 条漫」，点击率差很多。
