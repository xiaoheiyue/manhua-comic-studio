# 内测环境问卷

> 目的：不是投票决定方向，是搞清楚"谁在什么机器上、卡在哪"。
> 建议用问卷星 / 腾讯问卷建表，下面 12 题可直接照抄；回收 20 份就能看出该先修什么。

## 一、问卷题目

**1. 你的身份是？**（单选）
- 网文作者 / 漫画作者
- 短视频 / 漫剧从业者
- 开发者，想二次开发
- 只是好奇

**2. 你的系统**
- Windows 11 / Windows 10 / macOS / Linux / 不确定

**3. 显卡型号与显存**
- 8GB 以下 / 8GB / 12GB / 16GB / 24GB 以上 / 没有独显

**4. 你装过 ComfyUI 吗？**
- 没装过，也没听过
- 听过，没装
- 装过，能跑基础文生图
- 熟，自己搭过工作流

**5. 你能接受装环境花多久？**
- 15 分钟内 / 1 小时内 / 折腾一天也行 / 只想下载即用

**6. 你想用它做什么？**（多选）
- 把自己的小说做成条漫
- 做短篇漫画 / 同人
- 做漫剧分镜
- 做海报 / 表情包（创作工坊）
- 研究 / 二次开发

**7. 你手上待处理的文本大概多长？**
- 3000 字以内短篇 / 1 万字左右 / 10 万字以上长篇 / 还没想好

**8. 你最在意什么？**（排序，1 最重要）
- 角色长得一样
- 画风好看/统一
- 分镜像漫画、能读
- 出图速度
- 安装简单
- 不要钱 / 不要上传

**9. 你现在的替代方案是什么？**
- 手画 / 请画师
- 即梦 / 豆包 / Midjourney
- 其他开源工具
- 没有，硬扛

**10. 你愿意为它付费吗？**
- 不愿意，只想白嫖
- 愿意买断 < 100 元
- 愿意订阅 < 30 元/月
- 愿意为"代部署/定制"付钱

**11. 你愿意怎么参与？**（多选）
- 只使用，不提意见
- 报 bug / 提需求
- 写文档 / 翻译
- 提 PR 改代码
- 帮忙发作品宣传

**12. 留一句最想吐槽的**（开放题）

## 二、回收后看什么

| 信号 | 说明 | 动作 |
|---|---|---|
| 卡在"装 ComfyUI"超过 50% | 安装是最大门槛 | 优先做一键安装 + 模型检查脚本 |
| "角色一样"排第一超过 60% | 一致性是真需求 | 优先接 IP-Adapter / LoRA |
| 8GB 显存占多数 | 低显存是主战场 | 保持 int8、优化降级策略 |
| "只想下载即用"占多数 | 目标人群错位 | 考虑托管版，而不是硬推本地 |
| 愿意提 PR 的 ≥ 3 人 | 有共治基础 | 开 good first issues，给写权限 |

## 三、发问卷的话术

> 占两分钟，帮我决定先修什么。不收集手机号，答案只用来排优先级。
> 填完可以进内测群，装环境我帮你看。
