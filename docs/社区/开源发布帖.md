## GitHub Release v0.1.0

**漫画生成器 v0.1.0：把小说变成条漫的本地流水线**

第一个公开版本。不是"又一个套壳文生图"，是一套把"漫画成立"当目标的工程化流程。

### 它能做什么

```text
小说 → 精修 → 角色/场景 → 人设三视图 → 分镜 → 25 格 → 拼页 → 气泡 → 条漫 / PDF / ZIP
```

- **画风**：365 种 handraw 画风 × 36 主题色 × 40 阶调，按故事气质自动推荐
- **版式**：74 种漫画分页版式，自动编页，支持条漫 / 分页 / 混排
- **气泡**：先让模型按坐标画空白气泡，再定位填字；按细节密度与肤色网格避开人脸
- **自检**：每格检查白边、文字溢出、多余气泡、全黑，低于阈值自动重画
- **本地**：图像推理全在本机 ComfyUI；文本接口可换成任意 OpenAI 兼容端点

### 快速开始

```bash
git clone TODO
cd manhua-comic-studio
python -m venv .venv && .venv/Scripts/activate   # Windows
pip install -r requirements.txt
cp .env.example .env                             # 填 DEEPSEEK_API_KEY
python server.py                                 # http://127.0.0.1:7870
```

没有 GPU 也能先跑 `python selftest.py`，离线验证全链路。

### 已知边界（先说清楚）

- 同一张脸不能稳定保持，8GB 显存下这是模型能力限制
- 需要本地 ComfyUI + 十几 GB 模型权重（不随仓库分发）
- 不是 SaaS，没有账号/计费/多租户
- Windows 优先，Linux/macOS 可跑但要自己起 ComfyUI

## V2EX 分享帖

**标题**：开源了一个本地「小说 → 条漫」工具，Apache-2.0

正文：

写这个的起因很简单：我喜欢看小说，但不会画画。

市面上"小说转漫画"的工具不少，但大多是云端 API 套壳：按张计费、角色一致性靠运气、内容还得上传。我想做一个完全本地的：小说不出机器，图片不出机器，成本只有电费。

做了几个月，现在能跑通：小说 → 分析 → 人设 → 分镜 → 出图 → 拼页 → 气泡 → 条漫/PDF。

几个可能跟别人不一样的地方：
1. 分页版式是真的做了 74 种，按内容自动编页，不是"一页一格"。
2. 气泡是先生成空白气泡再定位填字，会避让人脸。
3. 每格出图后自检，白边/文字溢出/多余气泡会自动重画。
4. 有离线 selftest，不花 token 就能验证链路。

短板也直说：同脸不稳、要装 ComfyUI 和模型、Windows 优先。
