# 角色人设生成

- **阶段**：02_characters
- **代码位置**：`prompts.character_design_prompt`
- **用途**：为单个角色生成人设、硬特征、唯一记忆点与关键词。

## 输入变量

变量：`character`（分析结果）、`project`（含已有角色清单，用于差异化）。

## 提示词正文

### system

```text
你是一位漫画视觉开发设计师，擅长按指定画风写出精确、可落地成图像提示词的人设描述。你只输出结构化 JSON，不输出任何解释性文字。
```

### user

```text
请按上面的画风为这个角色设计人设。

【作品信息】
风格：Retro 90s Cel Anime & Korean Emotional Webtoon Illustration, Grainy Nostalgic Film Aesthetic（参考作者/风格：复古日系赛璐璐与韩系情绪动画 / Retro 90s Cel Anime & Korean Mood Webtoon；核心特征：复古日系二维动画与现代韩系情绪漫画融合的插画风格，具有1990年代手绘赛璐璐动画的朴素视觉质感；主题色：湖蓝、那不勒斯黄）
风格细化：冷色调、低照度、强调雨夜质感
故事梗概：林晚雨夜回到老宅，遇见沈砚，发现一只停在十一点四十七分的怀表。

【角色分析结果】
姓名：林晚
性别：女
年龄感：二十四岁
身份：旧宅继承人
性格特点：冷静克制
在故事中的作用：主角
是否群众角色：否

【已有角色清单（你必须和他们区分开）】
- 沈砚：沈砚：男三十岁上下，黑色三七分短发、长方脸、深眼窝、深灰长风衣、素圈银戒

【跨角色差异化硬约束（最重要）】
1. 你的角色在「发型轮廓 / 服装主色 / 体型年龄 / 唯一记忆点」这四项里，
   **至少 3 项必须与上面清单里的任何人都不同**。
2. 记忆点（疤痕、眼镜、耳饰、项链、怀表等）**不得与清单里已有的重复**，连近似写法都不行。
3. 不要用"冷白肤色""五官精致"这类人人都能写的词当特征，它们不构成辨识度。
4. 脸型与眼型如果和某人相近，就必须在发型、服装主色、记忆点上明显拉开。
5. 只做"加法"：小说没有写死的外貌由你补，但已写死的（发色/年龄/身份）不能改。

【人设描述必须包含以下内容】
1. 基本形象：性别、年龄感、身高体型、脸型、五官特征。在该画风下五官要精致，
   但要保持插画的概括性（清晰线稿、概括的鼻影与唇形），不要写成真人照片。
2. 发型与发色：发型样式、长度、发色，是否有特殊发饰。
3. 服装风格：日常服装、特殊场合服装、服装颜色和材质特点。小说中有服装变化描写时分别记录。
4. 气质与表情：整体气质（冷静/活泼/忧郁/威严等）与常见表情特征。
5. 标志性特征：疤痕、眼镜、佩剑、纹身、特殊饰品等（没有就写"无明显标志性特征"）。
6. 色彩方案：推荐该角色的主色调和辅助色，既要辨识度高又要与整体画面和谐。

【严格输出以下 JSON 结构】
{
  "design": "完整人设描述，按以下小标题分段书写，每段 1-2 句：\n【基本形象】【发型与发色】【服装风格】【气质与表情】【标志性特征】【色彩方案】",
  "hard_features": {
    "face": "脸型，从 rules/identity_rules.json 的 face 词表里选一个，如'瘦长脸'",
    "hair": "发型+发色+长度，一个短语，如'及肩黑发低马尾'",
    "eyes": "眼型，一个短语，如'细长上挑杏眼'",
    "outfit": "服装主色+款式，一个短语，如'炭黑短款风衣'",
    "build": "身形，一个短语，如'清瘦挺拔'",
    "signature": "唯一的视觉记忆点，一个短语，如'颈挂细银链旧U盘'",
    "palette": "主色 + 辅助色，如'炭黑/冷灰+雾蓝'"
  },
  "identity_tag": "全片唯一的记忆点（≤18 字），不得与任何已有角色重复",
  "keywords": [
    "6-10 个可直接放进图像提示词的外貌关键词，如'及腰黑长直发'、'米色风衣'、'苍白肤色'"
  ],
  "main_visual_prompt": "主视觉图的图像生成提示词（只描述画面，不含画风词）",
  "triple_view_prompt": "三视图的图像生成提示词（只描述画面，不含画风词）"
}

keywords 字段要特别用心：这些词会被拼成"身份卡"注入每一张分镜（≤90 字、逐字复用），
所以要具体、可视化、可复现，并且**按 importance 排序**（发型发色 → 脸型/眼型 → 服装 → 记忆点）。
```
