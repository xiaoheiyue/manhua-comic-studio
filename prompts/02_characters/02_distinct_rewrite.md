# 角色撞车重写

- **阶段**：02_characters
- **代码位置**：`prompts.character_distinct_rewrite_prompt`
- **用途**：两个角色过于相似时，定向重写后出现的那个。

## 输入变量

变量：`character`、`project`、`collisions`（撞车明细）。

## 提示词正文

### system

```text
你是一位漫画视觉开发设计师，擅长按指定画风写出精确、可落地成图像提示词的人设描述。你只输出结构化 JSON，不输出任何解释性文字。
```

### user

```text
你的角色「沈砚」和别的角色撞车了，读者分不出谁是谁。请重写人设。

【撞车明细】
- 与「林晚」撞车：脸型、发型

【当前人设】
【基本形象】男性，三十岁上下，清瘦，长方脸，深眼窝。
【发型与发色】黑色三七分短发。
【服装风格】深灰长风衣，白衬衫。
【标志性特征】右手无名指素圈银戒。
【色彩方案】深灰/白/冷蓝。

【当前关键词】
黑色三七分短发、长方脸、深眼窝、深灰长风衣、素圈银戒

【重写要求】
1. 保留小说已写死的外貌与身份（性别、年龄、发色、职业），只调整可以自由发挥的部分。
2. 在「发型轮廓 / 服装主色 / 体型年龄 / 唯一记忆点」里至少改 2 项，并写清改成了什么。
3. 新记忆点不得与下面任何角色重复：
- 林晚：左耳细银耳线
4. keywords 重新排序：发型发色 → 脸型/眼型 → 服装 → 记忆点；总数 6-9 个。
5. 只输出 JSON，结构为：
{"design": "重写后的人设（仍按【基本形象】…分段）",
  "hard_features": {"face": "", "hair": "", "eyes": "", "outfit": "", "build": "", "signature": "", "palette": ""},
  "identity_tag": "新的唯一记忆点",
  "keywords": ["…"],
  "reason": "一句话说明改了哪两项"}
```

## 期望输出

JSON：design / hard_features / identity_tag / keywords / reason
