# 分段分析合并

- **阶段**：01_analysis
- **代码位置**：`prompts.merge_analysis_prompt`
- **用途**：把多段分析合并去重成一份完整设定。

## 输入变量

变量：`partials`（分段结果）、`novel_head`。

## 提示词正文

### system

```text
你是一位资深的漫画编剧与剧本分析师，擅长把小说文本拆解成漫画制作所需的角色设定、场景设定与分镜脚本。你只输出结构化 JSON，不输出任何解释性文字。
```

### user

```text
下面是同一部小说分段分析得到的多份结果，请你合并成一份。

【合并规则】
1. 同一个角色出现在多份结果里时，合并为一条：取信息最全的字段，
   is_extra 只要有一份是 false 就取 false。
2. 同一个场景同理合并。
3. 情节线按故事发生顺序重新排列，去掉重复事件，保留关键转折与高潮。
4. 风格推荐取出现次数最多的那个；style_detail 综合各份建议写得更贴合作品。
5. summary 重新写成一段完整、连贯的梗概（150 字以内）。

【分段结果 JSON】
[
  {
    "summary": "样例",
    "characters": [],
    "scenes": []
  }
]

【原文开头（供你判断作品题材）】
雨夜的老宅

雨下得很大，敲在青瓦上噼啪作响。

林晚撑着一把断了一根伞骨的黑伞，站在城南那栋荒废了三十年的老宅门前。她今年二十四岁，身形清瘦，一头及腰的黑长直发被雨水打湿，贴在苍白的脸颊上。她穿着一件洗得发白的米色风衣，风衣口袋里露出半截泛黄的相片。

"就是这里了。"她低声说，声音几乎被雨声吞没。

大门虚掩着，铜环上落满灰尘。林晚伸手一推，门轴发出悠长的呻吟。院内荒草丛生，正屋的窗纸早已破损，风穿堂而过，卷起地上的落叶。

"谁？"一个沙哑的男声从正屋的阴影里传出来。

林晚脚步一顿。一个高瘦的男人从黑暗里走出来，他约莫三十岁上下，戴着一副圆框金丝眼镜，镜片后是一双极锐利的眼睛。他穿着深灰色的中山装，袖口磨得起了毛边，右手握着一盏老式煤油灯，左手垂在身侧，指节分明。

"你是……沈砚？"林晚的呼吸微微一滞。

"你认得我。"沈砚把煤油灯放在门边的石阶上，昏黄的光在两人之间铺开一小块暖

【严格输出与下面完全相同的 JSON 结构】
{
  "summary": "",
  "plotline": "",
  "key_points": [],
  "style": "彩色韩漫风格",
  "style_detail": "",
  "characters": [],
  "scenes": []
}

现在只输出合并后的 JSON。
```
