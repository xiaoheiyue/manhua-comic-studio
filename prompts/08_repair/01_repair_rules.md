# 返修规则对照表（问题 → 扣分 → 追加提示词）

> 来源：`comicgen/quality.py` 的 `inspect_shot()` / `repair_note()`。
> 返修提示词只会**追加**在出图提示词末尾，且遵循"正面描述、具体可执行"两条原则。

## 1. 结构化自检

| 问题代码 | 触发条件 | 扣分 | 自动处置 |
| --- | --- | --- | --- |
| `blank_image` | 画面接近纯色 | -70 | — |
| `too_dark` | 平均亮度 < 8 | -22 | — |
| `low_contrast` | 亮度标准差 < 12 | -12 | — |
| `white_border` | 四边白边 | -28 | 先裁边 |
| `text_overflow` | 最小字号仍溢出 | -36 | 缩字号/换框 |
| `bubble_detect_fail` | 计划 N>0，检测 0 | -14 | 整格兜底 |
| `bubble_count_mismatch` | 候选多于台词 | -6 | 多画的补背景 |
| `bubble_fallback` | 有台词没匹配到 | -6/个 | 程序补画 |
| `stray_balloon_covered` | 多画的气泡被补掉 | -4 | 调和填充 |
| `extra_balloon` | 旧模式：多余空白气泡 | -6 | 填"……"/盖掉 |
| `no_bubble` | 有台词却没有气泡框 | -24 | — |
| `no_reference` | 有角色但无参考图 | -8 | — |

## 2. 返修措辞（按问题）

| 问题 | 追加提示词 |
| --- | --- |
| 白边 | 画面满版出血到四边，构图完整占满画布，人物与背景一直延伸到画面边缘 |
| 文字溢出 | 气泡要画大一号，给文字留足空间；文字必须完整放在气泡里 |
| 气泡定位失败/数量不符/兜底 | 画面里只有 N 个空白气泡，严格按上面每个气泡的坐标与尺寸画，气泡纯白、黑色描边、内部没有文字，彼此不重叠 |
| 多余气泡（旧模式） | 画面中只画 N 个空白气泡，位置与尺寸严格按上面的说明 |
| 背景被气泡弄脏 | 画面里只保留人物、道具与场景，背景干净完整 |
| 气泡兜底（备用模式） | 画面上方保留更完整的浅色背景空间，人物与道具整体往下让一点 |
| 全黑/全白/过暗 | 画面不能全黑或全白，主体、人物和背景都要清晰可辨 |
| 有角色没参考图 | 严格按上面的人设描述锁定人物长相、发型、发色与服装 |

## 3. 组合示例（气泡定位失败 + 文字溢出）

```
【本轮返修要求，优先级最高】
画面里只有 1 个空白气泡，严格按上面每个气泡的坐标与尺寸画，
气泡纯白、黑色描边、内部没有文字，彼此不重叠；
气泡要画大一号，给文字留足空间。
```

## 4. 约束

- 一次只修 1~2 个问题，多了模型会顾此失彼；
- 返修**不改身份卡**，只改构图/气泡/光线；
- 返修可能越修越差，`imggen` 会保留最高分版本；
- 2 次仍不达标会标记失败，避免无限烧显卡。
