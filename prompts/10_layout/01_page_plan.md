# 分页与版式规划

- **阶段**：10_layout
- **代码位置**：`prompts.page_plan_prompt`
- **用途**：把连续分镜编成漫画页，并逐页选择 SB-*/WB-* 版式（格数必须匹配）。

## 输入变量

变量：`project`、`layouts_table`（版式清单）、`shot_lines`（分镜摘要）。

## 提示词正文

### system

```text
你是快看漫画平台的资深分镜主笔（导演），负责把小说改编成可以直接开画的条漫分镜。你懂镜头语言：景别、机位、构图、轴线、光线、画幅节奏、转场与留白。你只输出结构化 JSON，不输出任何解释性文字。
```

### user

```text
你是这部漫画的版面导演。请把下面的分镜编成漫画页，并逐页选择版式。

【作品】雨夜的老宅／画风：Retro 90s Cel Anime & Korean Emotional Webtoon Illustration, Grainy Nostalgic Film Aesthetic（参考作者/风格：复古日系赛璐璐与韩系情绪动画 / Retro 90s Cel Anime & Korean Mood Webtoon；核心特征：复古日系二维动画与现代韩系情绪漫画融合的插画风格，具有1990年代手绘赛璐璐动画的朴素视觉质感；主题色：湖蓝、那不勒斯黄）
【分镜总数】2 格；建议约 1 页（每页 2~5 格为主，重点页可 1 格）

【分镜清单（序号｜场景｜景别/机位｜beat｜节奏｜视觉权重｜台词数｜画面摘要）】
1. 城南老宅｜中景/平视｜beat=动作｜pacing=慢｜emph=normal｜台词1旁白0｜林晚在画面左侧门口停下，右手还搭在门把上，眼睛盯着楼梯口；前景是半开
2. 城南老宅｜近景/斜侧｜beat=对白｜pacing=中｜emph=normal｜台词1旁白0｜林晚在画面左侧低头，视线落在桌面；前景是桌沿，后景是窗外的雨；台灯从

【可用版式（编号｜名称｜格数｜强项）】
SB-001｜规则网格｜4格｜对白、日常
SB-002｜四格起承转合｜4格｜幽默、日常、喜剧
SB-003｜大格 + 小格｜4格｜对白、揭示、主次
SB-004｜顶部大格开场｜3格｜建立、转场、开场
SB-005｜底部大格收尾｜3格｜情绪、揭示、收尾
SB-006｜中央大格爆发｜4格｜动作、爆发、揭示
SB-007｜对角切割｜2格｜动作、冲突、对峙
SB-008｜Z 字阅读｜4格｜对白、日常、阅读流
SB-009｜S 型阅读｜4格｜情绪、蒙太奇、浪漫
SB-010｜螺旋阅读｜5格｜悬疑、内心、聚焦
SB-011｜放射型分镜｜5格｜动作、爆发、聚焦
SB-012｜碎片面板｜6格｜动作、冲突、混乱
SB-013｜破框构图｜3格｜动作、揭示、破框
SB-014｜跨格人物｜3格｜动作、连续
SB-015｜跨格背景｜3格｜建立、转场、空间
SB-016｜一镜到底｜3格｜连续、转场、长镜头

【编页规则（按优先级）】
1. **完整覆盖**：所有分镜按 1..2 的顺序各出现一次，不能漏、不能重复、不能乱序。
2. **格数匹配**：每页 shots 的数量必须等于该版式的格数。
3. **一页一个场景**：同一页尽量只放同一场景的连续格；确需跨场景时，用
   SB-034/SB-035/SB-044 这类"并行/交叉/时间轴"版式，一页最多跨 2 个场景。
4. **按内容选版式**，不要全篇一个模板：
   - 日常对白、信息平稳 → 规则网格 / 正反打 / Z 字阅读；
   - 场景开场、大空间 → 顶部大格 / 宽银幕 / 建立镜头版式；
   - 情绪落点、反转 → 底部大格 / 满版冲击 / 留白版式；
   - 动作、冲突 → 对角切割 / 碎片面板 / 动作分解；
   - 回忆、想象、电话、屏幕、时间流逝 → 闪回嵌套 / 手机聊天 / 时间轴；
   - 章末钩子或全页定格 → 1 格满版 / 跨页 / 海报式；
   - 原生条漫（WB-*）用于想保持"手机上一路下滑"手感的连续情绪/对白段。
5. **重点格落在大格**：标了 splash/main 的格优先放进该页最大的画格；
   不要把满版冲击格塞进 6 格小格里。
6. **不要连续 3 页用同一版式**；也不要为了多样而选不适合内容的花哨版式。
7. 只有 SB-069/070/071 这类"上图下文"版式需要 captions（每格一句说明，
   ≤40 字，写画面正在发生的事，不要和台词重复）；其它版式 captions 给空数组 []。

【严格输出以下 JSON】
{
  "pages": [
    {
      "layout_id": "版式编号，如 SB-001 / WB-001",
      "shots": [
        "按顺序的分镜序号，如 1,2,3,4；数量必须等于该版式格数"
      ],
      "rationale": "一句话：为什么这几格合成一页、为什么用这个版式",
      "captions": [
        "仅当版式带字幕栏时填写：每格 ≤40 字说明；否则留空数组"
      ]
    }
  ]
}
只输出 JSON。
```
