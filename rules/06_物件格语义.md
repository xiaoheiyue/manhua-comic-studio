# 06 · 物件格语义规则（手机 / 屏幕 / 纸张 / 桌面）

> 问题：物件特写里，模型会自己补一个人脸、一只手，甚至把碎屏手机画成"死者的遗照"。
> 这不是提示词没写"没有人"，而是 **"手机 + 血迹 + 死者" 的语义惯性**。

---

## 1. 先分三种物件格，不要用同一套提示词

| `object_mode` | 适用 | 画面核心 | 允许出现 |
| --- | --- | --- | --- |
| `物证照` | 碎屏手机、血迹、遗物、证物袋 | 俯拍、平放、比例尺、台面 | **只允许物件、台面、比例尺** |
| `屏幕界面` | 聊天记录、时间、号码、进度条 | 亮屏、抽象 UI、冷光 | 物件表面，不出现人像 |
| `环境细节` | 桌面、墙面、门缝、楼梯 | 材质、光影、空间 | 环境本身 |

导演层 `_classify_object_mode()` 自动判定；`Shot.object_mode` 落盘，回溯可见。

---

## 2. 提示词模板（按模式）

### 物证照

```
物证记录照：俯拍，物件平放在金属台面上，旁边放一把比例尺，
屏幕是黑色玻璃，表面只有裂纹、血迹与顶灯的长条反光；
画面里只有物件、台面、比例尺与反光
```

### 屏幕界面

```
屏幕亮着，显示冷色调的抽象色块、进度条与数字，表面有裂纹与玻璃反光
```

### 环境细节

```
画面是环境的一个局部，物件之外只有承托它的桌面、墙面与地面
```

共同约束：
- 不写"没有人物/没有人"（否定句会反向提示）；
- 不写"像指印/像一只手"这类比喻（会诱导手/人）；
- 物件格 `characters` 必须为空；
- 场景名去掉角色名（"陆鸣工作室"→"工作室"）。

---

## 3. 程序自检：物件格出现肤色 = 长人了

`quality.inspect_shot()` 新增：

- 条件：`characters` 为空 + 景别 `特写/近景`；
- 用 YCbCr 肤色阈值算低分辨率热区；
- 肤色占比 **>10%** → `object_face_hallucination`，扣 18 分；
- 该问题**强制返修**（`imggen` 的 `bubble_hard` 名单里），返修提示：

```
画面里只有物件与承托它的桌面/空间：物件的表面只有材质、裂纹、
血迹与反光，物件之外没有任何人、脸或手
```

> 这是粗筛，不是人脸检测：室内暖光、木质台面可能误报。
> 阈值 10% 是实测折中；误报只会多一次返修，不会静默放过。

---

## 4. 真机结果（Z-Image-Turbo，8GB）

| 版本 | 结果 |
| --- | --- |
| 原始物件提示词 | 手机屏上一个人像 + 一只手 |
| 加"物证记录照/平放桌面" | 手消失，手机平放；**屏幕仍被人像填充** |
| 只加"屏幕黑色玻璃/只有裂纹血迹" | 仍可能出人像——模型把"碎屏+血"理解成遗照 |
| **物证照模式 + 比例尺 + 金属台面 + 黑色玻璃** | **人像和手都消失**，画面是物证记录照；肤色占比 0.2% |
| 旧图（人像版） | 肤色占比 2.6%，被 `object_face_hallucination` 抓到 |

结论：
- "物证记录照 + 比例尺 + 金属台面" 是目前最有效的正向组合，比反复写"没有人"有效；
- 加肤色自检后，旧图/漏网图会被自动发现并强制返修；
- 需要手的镜头仍建议改"斜侧+手"（人物格），不要既写"物件特写"又指望模型不画人；
  也不要用"单人过肩"，前景肩背会被画成第二个人。

---

## 5. 分镜层建议

1. 手机/屏幕 + 血迹：优先拆成
   - 一格"斜侧：陆鸣戴指套的手把手机放上读盘器"（人物格，手是合理的）；
   - 一格"屏幕界面：时间/拨出记录"（屏幕界面模式，抽象 UI）；
2. 纯物证照只用于"需要让读者看清物证"的节点，不要连续两格；
3. 物件格不要配台词气泡（没有人物，气泡无处可指）；
4. 物件格在 `03_分镜/分镜脚本.json` 里应满足：`characters=[]`、`object_mode` 非空。

---

## 6. 验收

- [ ] `object_mode` 已写入分镜 JSON；
- [ ] 物件格 `characters=[]`；
- [ ] 出图后 `quality_issues` 不含 `object_face_hallucination`；
- [ ] 若含，确认已返修或人工重画；
- [ ] 回溯 `08_回溯/质量报告.json` 可见肤色占比。

## 7. handraw 风格 / 负向 / 分页补充

- **风格块照常注入**：物件格也要带 handraw「漫画分级特征 + 视觉语言 + 主题色」，
  否则同一页里物件格会变成另一种画风。
- **负向词**：物件格自动加"人物、人脸、人像、手、手指、人体、主角、角色"，
  以及"可读文字、乱码文字"；不要把这些写进正向。
- **正向描述**：只写"物件 + 承托它的台面/空间 + 材质/裂纹/反光"，
  不要写"画面里没有人"（负向词负责）。
- **分页**：物件/细节格适合 `inset`、小格、半页字幕栏；不要给整页满版
  （除非是章末揭示）。分格页生成时同样要带 `panel_orientation`。
- **风格选择**：物证照优先 FI（电影级写实）/ FF（3D 材质）/ FC（平面信息图），
  手绘漫画风（FA/FD）容易把手机/报纸画成涂鸦；这是推荐，不是硬规则。
