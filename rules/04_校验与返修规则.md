# 校验与返修规则（QA & Repair Rules）

> 三层门禁：**出图前（数据/提示词）→ 出图后（结构化质检）→ 导出前（成品）**。
> 前两层是确定性的，不依赖视觉大模型；第三层需要人工抽查。
> 机器可读版本：[`data/storyboard_rules.json`](data/storyboard_rules.json) 的 `validation` 段。

---

## 1. 出图前门禁（Pre-flight）

### G1 角色层

| 检查 | 代码 | 处置 |
| --- | --- | --- |
| 身份卡缺失/超长 | `character_no_card` | 自动重算（`identity_card()`） |
| 记忆点重复 | `character_tag_collision` | 自动追加唯一点缀 |
| 两角色撞车（≥3 项相同，或 ≥2 项相同且相似度 >0.62，或记忆点重复） | `character_collision` | 重写一次 → 仍撞车则加点缀 |
| 撞车已用点缀区分 | `character_collision_patched` | 只提示，重出图后抽检 |
| 身份卡里出现与当前画风冲突的"写实/照片/3D" | `character_realism` | 仅当 handraw 风格不是 FI/FF 时替换；FI 写实风保留 |
| 主视图/姿态总图外层服装不一致 | `character_outfit_drift` | 只保留第一件外层（`CHARACTER_SINGLE_OUTERWEAR`） |
| 角色无眼镜但姿态总图出现眼镜/眼罩 | `character_glasses_hallucination` | 负向词 + 重画姿态总图 |

### G2 分镜层

| 检查 | 代码 | 处置 |
| --- | --- | --- |
| 描述复述景别/机位 | `desc_camera_words` | 自动删掉开头镜头词 |
| 描述带引号/台词 | `bad_description` | 自动抽出台词（`clean_description`） |
| 描述 <28 字或 >110 字 | `bad_description` | 告警；重拍时可修 |
| 出现"作为视觉主体"等注入语 | `meta_subject` | 自动删除，并从物件格移除角色 |
| 物件/屏幕格里有角色 | `object_shot_with_face` | 自动移除角色（改走物件提示词） |
| 物件格出现大面积肤色 | `object_face_hallucination` | 扣 18 分、强制返修"只画物件" |
| 双人格 ≥2 条台词 | `two_shot_dialogue` | 告警（建议拆格，不自动拆） |
| 3~4 人群像 | `multi_shot_cast` | info；不拆，抽检每张脸是否可区分 |
| 3~4 人同框 ≥2 条台词 | `multi_shot_dialogue` | 告警；只留 1 条，其余转画外音 |
| 5 人及以上 | `too_many_characters` | danger（必须拆成群像 + 单人反应格） |
| speaker 不在 characters 且未标 offscreen | `speaker_not_visible` | 自动标 `offscreen=true` + 尾巴 none |
| speaker 为空 | `empty_speaker` | 自动标 offscreen + 气泡顶部居中 |
| 气泡槽位与站位不符 | `bubble_side_mismatch` | 自动翻转左右 |
| 模型多画的气泡 | `bubble_count_mismatch` | 按气泡形状补成背景 + 返修"只有 N 个" |
| 气泡定位失败 | `bubble_detect_fail` | 整格程序兜底 + 返修"按坐标画 N 个" |
| 模型没画到位 | `bubble_fallback` | 程序补画 + 返修 |
| 同景别/同机位连续 >2 | `same_shot_run` / `same_angle_run` | 自动打断 |
| 新场景无建立镜头 | `no_establishing` | 自动补（物件特写除外） |
| 近景占比 <24% | `low_closeup` | 自动提升带台词的中景 |
| 画幅档位 <3 种 | `flat_scale` | 自动重排 |
| 无钩子 | `no_hook` | 自动标记最后一格 |
| 相邻描述雷同（相似度 >0.88） | `duplicate_panel` | 告警 |
| 总格数超过 16 格/千字 | `too_many_shots` | 合并同场景静止格 |
| 双人同框 >25% | `two_shot_ratio` | 拆成说话人单人 + 听者反应单人（对手用画外音） |
| 近景+特写 >30% | `closeup_high` | 近景降中景 |
| 单人格出现人群/关系词（两人/对方/路人/肩背…） | `solo_crowd_words` | 描述侧清洗；出图侧 castguard 再去一次 |
| 单人格描述出现画面外角色名 | `solo_ghost_names` | 删除/替换成"画面外的方向"（提示词里出现谁就画谁） |
| 过肩机位（单/双人都可能多画一个前景人） | `over_shoulder_risk` | 改斜侧/平视；用门框/桌沿做前景 |
| 单人远景画面边缘留白大 | `solo_wide_empty` | 补"人物占画面主体" |
| 双人同框但两人特征撞车 | `pair_collision` | 注入差异对照；仍分不清就重做人设 |
| 双人同框没有左右站位 | `pair_no_sides` | 按角色顺序补一左一右 |

### G3 提示词层

| 检查 | 代码 | 处置 |
| --- | --- | --- |
| 正向总长度 >900 字 | `prompt_too_long` | 按预算裁剪（不切 handraw 风格块） |
| 正向出现"不要/非" | `prompt_forbidden` | 移到 negative 节点；正向改写 |
| 正向出现"分镜/一格/漫画格" | `prompt_layout_leak` | 改成"横向宽幅/竖向长构图/近乎方形" |
| 人数声明 ≠ characters 数量 | `prompt_count_mismatch` | 重新生成 |
| 身份卡与 `identity_card()` 不一致 | `prompt_card_drift` | 以 `identity_card()` 为准 |
| 出现画面外角色名 | `prompt_ghost_name` | 删除该名字 |
| 无台词却提到"气泡" | `prompt_bubble_leak` | 删除气泡段 |
| handraw 风格块缺失/重复/编号泄漏 | `prompt_style_block` | 重新注入；编号不进提示词 |
| 双人卡被从中间切断（如"眼睛（画面左侧…"） | `prompt_card_cut` | 改用 94 字短卡；只整段丢弃，不切字 |
| 单人格正向仍出现"两人/对方/人群/路人/肩背" | `prompt_solo_crowd` | 用 `castguard.depopulate_text` 再清洗一次 |
| 双人正向没有具体差异对照 | `prompt_pair_no_contrast` | 注入 `contrast_block`（脸/眼/发/外套/记忆点） |
| 姿态骨架无头部关键点/多头 | `prompt_pose_invalid` | 跳过骨架，只用提示词；坏图移出库 |

### G4 风格 / 分页 / 负向层

| 检查 | 代码 | 处置 |
| --- | --- | --- |
| 风格编号不存在 | `style_unknown` | 回退本地推荐 |
| 阶调不在 T-01~T-40 | `style_tone_unknown` | 按文本自动重选 |
| 触发词含编号/风格名/负面词 | `style_trigger_dirty` | 清理后重写 |
| 工作流没有 negative 文本节点 | `workflow_no_negative` | 提示换工作流；负向词不生效 |
| `COMFY_CFG<=1` 且开了负向词 | `negative_ineffective` | 提示调到 1.2~1.4，或关掉负向开关 |
| 页计划漏格/重格/顺序乱 | `page_coverage_broken` | 自动重排或退回本地规划 |
| 页格数与版式不符 | `page_layout_mismatch` | 换版式/重排 |
| 单格页 >35% 或连续 3 页单格 | `page_fragmented` | AI 方案退回本地 |
| 分格页格子比例 <0.32 / >2.8 | `page_cell_extreme` | 换版式或给格子加留边 |

> 实现位置：`director.validate()`（G2 大部分）、`pipeline.build_shot_prompt()`
> （G3）、`pipeline.ensure_character_distinctness()`（G1）。

### G5 重排 / 清空 / 风格切换

| 检查 | 代码 | 处置 |
| --- | --- | --- |
| 重排后仍用旧图合成 | `page_stale_after_replan` | 重排不自动合成，页面标“待生成” |
| 出图比例沿用旧 `shot.panel_size` | `panel_aspect_stale` | 从当前 `page.cells` 计算画幅 |
| 换风格后旧缩略图仍在 | `style_stale_images` | 提示“应用风格并清空旧图”或手动清空 |

## 2. 出图后门禁（Post-flight，结构化）

`comicgen/quality.py` 的能量范围：**只查硬伤，不判美丑**。

| 检查 | 罚分 | 自动处置 | 返修措辞（写进下一轮提示词） |
| --- | --- | --- | --- |
| 纯色/空白图 | -70 | — | 画面不能全黑或全白，主体、人物和背景都要清晰可辨 |
| 过暗（mean<8） | -22 | — | 同上 + 提亮主体 |
| 低对比 | -12 | — | 增加明暗层次 |
| 四边白边 | -28 | 先裁边 | 画面满版出血到四边，构图完整占满画布 |
| 文字溢出 | -36 | 缩字号/换更大检测框 | 气泡要画大一号，给文字留足空间 |
| 气泡定位失败 | -14 | 程序兜底 | 按上面的坐标画出 N 个空白气泡 |
| 气泡数量不符 | -6 | 多画的补成背景 | 画面里只有 N 个空白气泡，彼此不重叠 |
| 气泡兜底（模型没画） | -6/个 | 程序补画 | 必须在指定位置画出白底黑边的空白气泡 |
| 有台词没气泡 | -24 | — | 台词对应的空白气泡必须画出来，不能省略 |
| 有角色无参考图 | -8 | — | 严格按上面的人设描述锁定人物长相、发型、发色与服装 |

> 主链路分两种：
> - 基础文生图 `IMAGE_DRAW_BUBBLES=True`：模型画气泡、程序回填，补画/定位失败会返修；
> - `style_color` 色彩迁移：气泡由程序画（`bubble_programmatic=True`），
>   不再检查"模型气泡定位"，也不会因为气泡被染色而误报。
>
> 角色图额外人工/半自动检查：主视图与姿态总图是否同一张脸、同一套服装、有没有透明衣料/薄纱、
> 无眼镜角色有没有被画出眼镜。发现即用对应负向词重画，不改人设正文。


通过分 `IMAGE_QUALITY_PASS_SCORE=82`，可交付底线 `IMAGE_QUALITY_ACCEPT_SCORE=70`；
不合格自动返修 `IMAGE_AUTO_REPAIR_RETRIES=2` 次，**保留最高分版本**。

### 2.1 新增建议（等模型启动后再开）

| 检查 | 方法 | 阈值 |
| --- | --- | --- |
| 画里人数与分镜不符 | 人脸检测（InsightFace / YOLO-face） | 单人分镜检测到 >1 张脸 → 返修 |
| 画里出现意料外的大脸 | 同上 + 面积占比 | 物件格检测到人脸 → 返修 |
| 气泡数量不符 | 空白连通域计数 | 与 `bubble_plan` 差 ≥2 → 返修 |
| 双人同框脸相似 | 人脸 embedding 余弦相似度 | >0.75 → 警示（可能是同一个人） |

这些需要额外模型，当前不默认开启；代码里预留 `IMAGE_FACE_CHECK` 开关。

## 3. 返修措辞规则

返修提示词只能**追加在末尾**，且必须：

1. **正面表述**（同 D1）：`气泡画大一号` 而不是 `不要溢出`；
2. **具体可执行**：`只画 2 个空白气泡` 而不是 `气泡别太多`；
3. **一次只修 1~2 个问题**（多了模型会顾此失彼）；
4. **不改身份卡**：返修只改构图/气泡/光线，不改人物特征；
5. **保留最高分**：返修可能越修越差，必须留底。

模板：

```
【本轮返修要求，优先级最高】
1. 画面里只有 1 个人，是陆鸣；不要出现第二张脸。
2. 气泡放在画面右上角，尺寸按上面的坐标，尾巴指向她的嘴。
3. 画面满版出血到四边。
```

## 4. 导出前门禁（成品）

| 检查 | 方法 |
| --- | --- |
| 每格都有成品图 | `shot.image_path` 存在 |
| 没有连续 3 格空白/失败 | 统计 `status` |
| 条漫拼接无拉伸 | 每块宽度一致、PDF 页面尺寸取图片自身 |
| 气泡不压脸 | 人工抽查（尤其双人格） |
| 角色抽检 10 格 | 按 01 文档 H10 |
| 台词归属 | 每条台词都能指出"谁说的、气泡在哪一侧" |

## 5. 已知限制

- **没有视觉大模型**：程序不知道"这张脸像不像"，只能查白边、气泡、明暗等硬伤；
- **人脸一致性无法自动判定**：需要人工抽检或接入人脸 embedding（见 2.1）；
- **双人格的尾巴只能估算**：程序按站位+景别估脸部位置，实际脸在哪由模型决定；
  所以最稳的做法仍然是**一格一人**；
- **返修有上限**：2 次仍不达标会标记失败，避免无限烧显卡。
- **没有真正的 inpaint**：旧图里模型自绘的气泡只能用调和填充补成柔和背景块，
  复杂背景上会看得出补丁；最干净的做法是重出这一格。

## 6. 怎么用

```powershell
# 离线自检（不联网、不耗显存）
env\Scripts\python.exe selftest.py

# 真实联调（需要 ComfyUI + DeepSeek 密钥）
env\Scripts\python.exe apitest.py
```

界面上：

- 阶段 4 「整理分镜」→ 跑 `director.normalize()` + `validate()`；
- 阶段 4 「导演优化」→ 让文本模型重拍一遍（会作废旧成品图）；
- 阶段 5 「单格重做」→ 用当前提示词重画一格，保留最高分；
- 工程与产物页 → 看自检分数与问题代码。
